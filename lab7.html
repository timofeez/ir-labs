ЛР7. Булев индекс#

Задание (Задания-2021.pdf): построить булев индекс в собственном бинарном расширяемом формате, описать формат побайтово; прямой индекс (заголовки и ссылки документов); термы в нижнем регистре. В отчёте: представление документов, метод сортировки, число термов, средняя длина терма в сравнении со средней длиной токена, скорость индексации, как будет масштабироваться. Структуры данных — свои (C++ без STL).

1. От матрицы «терм — документ» к обратному индексу#

Матрица инцидентности: строки — термы, столбцы — документы, 1 если терм есть в документе. Булев запрос — побитовые операции над строками. Но у меня 642 124 терма × 65 509 документов = 42 млрд клеток, а единиц — 16,9 млн (0,04 %). Хранить нули бессмысленно.

Обратный индекс (inverted index): для каждого терма — отсортированный список номеров документов (posting list, «координатный блок»):

электровоз → [3, 17, 45, 102, …]   df = 566
колея      → [17, 30, 45, …]

«Обратный» — потому что обычно документ → слова, а здесь слово → документы. df (document frequency) — длина списка. Списки отсортированы, чтобы пересекать их за O(m + n) (ЛР8).

2. Части индекса#

Часть Содержимое Зачем
Словарь (DICT + TERMSTR) отсортированные термы, у каждого df и смещение списка двоичный поиск терма за O(log T)
Списки документов (POSTINGS) номера документов по возрастанию пересечение/объединение слиянием
Прямой индекс (DOCS) по номеру документа — источник, pageid, заголовок, URL страница выдачи

3. Построение индекса (индексатор, C++)#

Классическая схема из лекции и учебника Маннинга:

  1. Разбор корпуса: для каждого документа — запись прямого индекса и токенизация заголовка и текста.
  2. Каждый токен → номер терма через хеш-таблицу TermTable (новый терм получает следующий номер).
  3. Пары (терм, документ) — каждая один раз: lastDoc[терм] помнит последний документ, где терм встречался, повтор в том же документе пропускается. Пара упакована в одно 64-битное число терм << 32 | документ.
  4. Сортировка пар по терму — подсчётом (counting sort): считаем, сколько пар у каждого терма, префиксные суммы дают начало каждого списка, затем раскладываем. Это O(n) и стабильно — документы в каждом списке остаются по возрастанию (документы шли по порядку).
  5. Сортировка словаря — номера термов сортируются слиянием по строкам термов (побайтовое сравнение UTF-8): O(T log T) гарантированно, стабильно, годится для внешней памяти.
  6. Запись файла по секциям.

// ---------------------------------------------------------------- сортировка слиянием
// Сортирует массив id термов по строкам термов (восходящая, итеративная, стабильная).
static void merge_sort_terms(uint32_t *a, size_t n, const TermTable &tt) {
    uint32_t *tmp = (uint32_t *)malloc(n * sizeof(uint32_t));
    uint32_t *src = a, *dst = tmp;
    for (size_t width = 1; width < n; width *= 2) {
        for (size_t lo = 0; lo < n; lo += 2 * width) {
            size_t mid = lo + width < n ? lo + width : n;
            size_t hi = lo + 2 * width < n ? lo + 2 * width : n;
            size_t i = lo, j = mid, k = lo;
            while (i < mid && j < hi) {
                uint32_t x = src[i], y = src[j];
                if (cmp_bytes(tt.pool.a + tt.off[y], tt.len[y], tt.pool.a + tt.off[x], tt.len[x]) < 0)
                    dst[k++] = src[j++];
                else
                    dst[k++] = src[i++];
            }
            while (i < mid) dst[k++] = src[i++];
            while (j < hi) dst[k++] = src[j++];
        }
        uint32_t *t = src; src = dst; dst = t;
    }
    if (src != a) memcpy(a, src, n * sizeof(uint32_t));
    free(tmp);
}

// Сравнение байтовых строк (лексикографически по беззнаковым байтам).
static inline int cmp_bytes(const char *a, size_t la, const char *b, size_t lb) {
    size_t m = la < lb ? la : lb;
    int r = memcmp(a, b, m);
    if (r) return r;
    return la < lb ? -1 : la > lb ? 1 : 0;
}

4. Бинарный формат index.bin#

Все числа little-endian. Файл = заголовок + таблица секций + секции (каждая выровнена на 8 байт).

Заголовок, 16 байт:

Байты Тип Значение
0–3 char[4] сигнатура BIDX
4–7 u32 версия формата = 1
8–11 u32 число секций (4)
12–15 u32 флаги: бит 0 = индекс основ (ЛР4)

Таблица секций, по 24 байта на секцию: тип u32, резерв u32, смещение u64, размер u64.

Тип Секция Устройство
1 DOCS u32 число документов; u64 × N смещений записей; записи: u8 источник (0 ru, 1 en, 2 «Гудок»), u32 pageid, u16 длина + байты заголовка, u16 длина + байты URL
2 DICT u32 число термов; записи по 24 байта в порядке сортировки: u32 смещение строки в TERMSTR, u16 длина, u16 резерв, u32 df, u32 резерв, u64 смещение списка в POSTINGS
3 TERMSTR байты всех термов подряд (UTF-8)
4 POSTINGS u32 номера документов, списки подряд

Расширяемость: новые данные — новые секции (позиции слов для фразового поиска, сжатые списки, веса tf-idf): старые программы читают таблицу секций и неизвестные типы просто пропускают. Поле флагов уже использовано в ЛР4 (индекс основ), резервные поля — на будущее.

Реальные значения моего индекса (python lab7.py format):

0..3    42 49 44 58   сигнатура BIDX          DOCS      смещение 112          размер 8 456 596
4..7    01 00 00 00   версия 1                DICT      смещение 8 456 712    размер 15 410 980
8..11   04 00 00 00   4 секции                TERMSTR   смещение 23 867 696   размер 8 806 181
12..15  00 00 00 00   флаги 0                 POSTINGS  смещение 32 673 880   размер 67 760 752

lab_boolean/src/search.cpp — Index строки 11–78
// ---------------------------------------------------------------- загруженный индекс
struct Index {
    char *data = nullptr;
    uint64_t size = 0;
    const char *docs = nullptr, *dict = nullptr, *termstr = nullptr, *postings = nullptr;
    uint32_t nDocs = 0, nTerms = 0;
    bool stemmed = false;          // в индексе основы слов -> слова запроса тоже стеммируются

    bool load(const char *path) {
        FILE *f = fopen(path, "rb");
        if (!f) { fprintf(stderr, "cannot open %s\n", path); return false; }
        #ifdef _WIN32
        _fseeki64(f, 0, SEEK_END); size = (uint64_t)_ftelli64(f); _fseeki64(f, 0, SEEK_SET);
#else
        fseeko(f, 0, SEEK_END); size = (uint64_t)ftello(f); fseeko(f, 0, SEEK_SET);
#endif
        data = (char *)malloc(size);
        if (fread(data, 1, size, f) != size) { fprintf(stderr, "read error\n"); return false; }
        fclose(f);
        if (memcmp(data, INDEX_MAGIC, 4) != 0) { fprintf(stderr, "bad magic\n"); return false; }
        if (rd32(data + 4) != INDEX_VERSION) { fprintf(stderr, "unsupported version\n"); return false; }
        uint32_t nsec = rd32(data + 8);
        for (uint32_t i = 0; i < nsec; i++) {
            const char *e = data + HEADER_SIZE + i * SECTION_ENTRY_SIZE;
            uint32_t type = rd32(e);
            const char *p = data + rd64(e + 8);
            if (type == SEC_DOCS) docs = p;
            else if (type == SEC_DICT) dict = p;
            else if (type == SEC_TERMSTR) termstr = p;
            else if (type == SEC_POSTINGS) postings = p;
            // неизвестные секции пропускаются — так формат расширяется без поломки старых программ
        }
        if (!docs || !dict || !termstr || !postings) { fprintf(stderr, "missing section\n"); return false; }
        nDocs = rd32(docs);
        nTerms = rd32(dict);
        stemmed = (rd32(data + 12) & FLAG_STEMMED) != 0;   // флаги заголовка
        return true;
    }

    // Двоичный поиск терма в отсортированном словаре. Возвращает номер записи или -1.
    long find_term(const char *s, int n) const {
        long lo = 0, hi = (long)nTerms - 1;
        while (lo <= hi) {
            long mid = (lo + hi) / 2;
            const char *e = dict + 4 + (size_t)mid * DICT_ENTRY_SIZE;
            int c = cmp_bytes(termstr + rd32(e), rd16(e + 4), s, n);
            if (c == 0) return mid;
            if (c < 0) lo = mid + 1; else hi = mid - 1;
        }
        return -1;
    }

    void postings_of(long entry, Vec<uint32_t> &out) const {
        out.clear();
        if (entry < 0) return;
        const char *e = dict + 4 + (size_t)entry * DICT_ENTRY_SIZE;
        uint32_t df = rd32(e + 8);
        out.resize(df);
        memcpy(out.a, postings + rd64(e + 16), (size_t)df * 4);
    }

    // Заголовок и URL документа из прямого индекса.
    void doc_info(uint32_t d, const char *&title, int &tl, const char *&url, int &ul) const {
        const char *r = docs + rd64(docs + 4 + 8ull * d);
        tl = rd16(r + 5); title = r + 7;
        ul = rd16(r + 7 + tl); url = r + 9 + tl;
    }
};

6. Масштабирование#

  • ×10 (650 тыс. документов, ~3 ГБ): в память ещё помещается (~3 ГБ), время ~50 с — линейно.
  • ×100 и больше — пары не помещаются в память → блочная индексация: SPIMI (single-pass in-memory indexing) или BSBI — индексировать порциями, частичные индексы на диск, потом многопутевое слияние отсортированных списков. Сортировка слиянием словаря для этого уже подходит.
  • ×1000 — распределённая индексация (шардирование по документам или термам, MapReduce).
  • Сжатие: хранить разности соседних номеров (дельта-кодирование) переменной длиной (VByte, Elias-гамма, Голомб) — индекс в разы меньше; словарь — фронтальное кодирование префиксов.

9. Вопросы на защите#

  • Почему обратный индекс, а не матрица? Матрица на 99,96 % из нулей.
  • Почему списки отсортированы? Пересечение и объединение двумя указателями за O(m + n).
  • Какие сортировки и почему? Пары — подсчётом (O(n), стабильно, документы остаются по возрастанию); словарь — слиянием (O(T log T) гарантированно, стабильно, внешняя память).
  • Что значит расширяемый формат? Таблица секций: новые данные — новые секции, старые программы их пропускают; флаги в заголовке.
  • Как ищется терм? Двоичный поиск в отсортированном словаре.
  • Почему без STL? Требование курса: структуры данных индекса — свои (Vec, TermTable, сортировки).
  • Как масштабировать? SPIMI/BSBI + слияние, сжатие списков, распределённая индексация.

// Индексатор: строит булев индекс (прямой + обратный) в собственном бинарном формате.
//
// Вход:  corpus.tsv — по документу на строку: источник \t pageid \t заголовок \t URL \t текст
// Выход: index.bin
// Запуск: indexer corpus.tsv index.bin [--stem]
//   --stem — в индекс попадают основы слов (стемминг, src/stem.h), а не словоформы
#include "common.h"
#include "stem.h"

// ---------------------------------------------------------------- сортировка слиянием
// Сортирует массив id термов по строкам термов (восходящая, итеративная, стабильная).
static void merge_sort_terms(uint32_t *a, size_t n, const TermTable &tt) {
    uint32_t *tmp = (uint32_t *)malloc(n * sizeof(uint32_t));
    uint32_t *src = a, *dst = tmp;
    for (size_t width = 1; width < n; width *= 2) {
        for (size_t lo = 0; lo < n; lo += 2 * width) {
            size_t mid = lo + width < n ? lo + width : n;
            size_t hi = lo + 2 * width < n ? lo + 2 * width : n;
            size_t i = lo, j = mid, k = lo;
            while (i < mid && j < hi) {
                uint32_t x = src[i], y = src[j];
                if (cmp_bytes(tt.pool.a + tt.off[y], tt.len[y], tt.pool.a + tt.off[x], tt.len[x]) < 0)
                    dst[k++] = src[j++];
                else
                    dst[k++] = src[i++];
            }
            while (i < mid) dst[k++] = src[i++];
            while (j < hi) dst[k++] = src[j++];
        }
        uint32_t *t = src; src = dst; dst = t;
    }
    if (src != a) memcpy(a, src, n * sizeof(uint32_t));
    free(tmp);
}

// ---------------------------------------------------------------- запись
static void w16(FILE *f, uint16_t v) { fwrite(&v, 2, 1, f); }
static void w32(FILE *f, uint32_t v) { fwrite(&v, 4, 1, f); }
static void w64(FILE *f, uint64_t v) { fwrite(&v, 8, 1, f); }
static void pad8(FILE *f, uint64_t &pos) { while (pos % 8) { fputc(0, f); pos++; } }
static uint64_t align8(uint64_t x) { return (x + 7) & ~(uint64_t)7; }

static void put16(Vec<char> &b, uint16_t v) { b.append((const char *)&v, 2); }
static void put32(Vec<char> &b, uint32_t v) { b.append((const char *)&v, 4); }

int main(int argc, char **argv) {
    if (argc < 3) { fprintf(stderr, "usage: indexer corpus.tsv index.bin [--stem]\n"); return 1; }
    bool useStem = argc > 3 && strcmp(argv[3], "--stem") == 0;
    FILE *in = fopen(argv[1], "rb");
    if (!in) { fprintf(stderr, "cannot open %s\n", argv[1]); return 1; }

    double t0 = now_sec();
    LineReader lr(in);
    TermTable tt;              // все различные словоформы (токены после нормализации)
    TermTable stemTab;         // основы слов (только при --stem)
    Vec<uint32_t> toStem;      // toStem[id словоформы] = id основы: стемминг делается один раз на словоформу
    Vec<uint32_t> lastDoc;     // lastDoc[termId] — последний документ, где встречался терм
    Vec<uint64_t> pairs;       // пары (termId << 32 | docNo), по одной на (терм, документ)
    Vec<char> docsBlob;        // записи прямого индекса
    Vec<uint64_t> docOff;      // смещение записи каждого документа в docsBlob
    uint64_t textBytes = 0, tokens = 0, tokenChars = 0;
    uint32_t docNo = 0;
    char tok[MAX_TERM_BYTES + 4], sb[MAX_TERM_BYTES + 8];

    while (lr.next()) {
        char *s = lr.line.a; size_t n = lr.line.n;
        if (n && s[n - 1] == '\r') n--;
        // разбор полей: источник, pageid, заголовок, URL, текст
        char *f[5]; size_t fl[5]; int k = 0; size_t st = 0;
        for (size_t i = 0; i <= n && k < 5; i++) {
            if (i == n || (s[i] == '\t' && k < 4)) { f[k] = s + st; fl[k] = i - st; k++; st = i + 1; }
        }
        if (k < 5) continue;

        // запись прямого индекса: u8 источник, u32 pageid, u16+байты заголовок, u16+байты URL
        docOff.push(docsBlob.n);
        // источник: 0 = ruwiki, 1 = enwiki, 2 = gudok (газета «Гудок»)
        uint8_t source = (fl[0] >= 1 && f[0][0] == 'e') ? 1 : (fl[0] >= 1 && f[0][0] == 'g') ? 2 : 0;
        docsBlob.push((char)source);
        put32(docsBlob, (uint32_t)strtoul(f[1], nullptr, 10));
        uint16_t tl = (uint16_t)(fl[2] < 65535 ? fl[2] : 65535), ul = (uint16_t)(fl[3] < 65535 ? fl[3] : 65535);
        put16(docsBlob, tl); docsBlob.append(f[2], tl);
        put16(docsBlob, ul); docsBlob.append(f[3], ul);

        // индексируем заголовок и текст
        for (int part = 2; part <= 4; part += 2) {
            const char *p = f[part]; size_t pn = fl[part], pos = 0;
            textBytes += pn;
            int chars, tlen;
            while ((tlen = next_token(p, pn, pos, tok, chars)) > 0) {
                tokens++; tokenChars += chars;
                bool isNew;
                uint32_t id = tt.get_or_add(tok, tlen, isNew);
                if (useStem) {
                    if (isNew) {                       // новая словоформа: находим её основу
                        bool newStem;
                        int sl = stem::stem(tok, tlen, sb);
                        toStem.push(stemTab.get_or_add(sb, sl, newStem));
                        if (newStem) lastDoc.push(UINT32_MAX);
                    }
                    id = toStem[id];                   // в индекс идёт основа
                } else if (isNew) {
                    lastDoc.push(UINT32_MAX);
                }
                if (lastDoc[id] != docNo) {            // каждая пара (терм, документ) — один раз
                    lastDoc[id] = docNo;
                    pairs.push(((uint64_t)id << 32) | docNo);
                }
            }
        }
        docNo++;
        if (docNo % 5000 == 0) fprintf(stderr, "indexed %u docs\n", docNo);
    }
    fclose(in);
    double tParse = now_sec();
    TermTable &ix = useStem ? stemTab : tt;   // таблица термов индекса: основы или словоформы

    // ---- сортировка постингов по термам: сортировка подсчётом (стабильная, O(n))
    size_t T = ix.size;
    Vec<uint64_t> start; start.resize(T + 1);
    memset(start.a, 0, (T + 1) * sizeof(uint64_t));
    for (size_t i = 0; i < pairs.n; i++) start[(pairs[i] >> 32) + 1]++;
    for (size_t t = 0; t < T; t++) start[t + 1] += start[t];
    Vec<uint32_t> postings; postings.resize(pairs.n);
    {
        Vec<uint64_t> fill; fill.resize(T);
        memcpy(fill.a, start.a, T * sizeof(uint64_t));
        for (size_t i = 0; i < pairs.n; i++)
            postings[fill[pairs[i] >> 32]++] = (uint32_t)pairs[i];   // документы уже по возрастанию
        fill.release();
    }
    pairs.release();

    // ---- сортировка словаря: сортировка слиянием по строкам термов
    Vec<uint32_t> order; order.resize(T);
    for (size_t t = 0; t < T; t++) order[t] = (uint32_t)t;
    merge_sort_terms(order.a, T, ix);
    double tSort = now_sec();

    // ---- запись файла
    FILE *out = fopen(argv[2], "wb");
    if (!out) { fprintf(stderr, "cannot create %s\n", argv[2]); return 1; }
    const uint32_t NSEC = 4;
    uint64_t szDocs = 4 + 8ull * docNo + docsBlob.n;
    uint64_t szDict = 4 + (uint64_t)DICT_ENTRY_SIZE * T;
    uint64_t szStr = ix.pool.n;
    uint64_t szPost = 4ull * postings.n;
    uint64_t offDocs = align8(HEADER_SIZE + SECTION_ENTRY_SIZE * NSEC);
    uint64_t offDict = align8(offDocs + szDocs);
    uint64_t offStr = align8(offDict + szDict);
    uint64_t offPost = align8(offStr + szStr);

    fwrite(INDEX_MAGIC, 1, 4, out); w32(out, INDEX_VERSION); w32(out, NSEC); w32(out, useStem ? FLAG_STEMMED : 0);
    uint32_t types[NSEC] = {SEC_DOCS, SEC_DICT, SEC_TERMSTR, SEC_POSTINGS};
    uint64_t offs[NSEC] = {offDocs, offDict, offStr, offPost}, sizes[NSEC] = {szDocs, szDict, szStr, szPost};
    for (uint32_t i = 0; i < NSEC; i++) { w32(out, types[i]); w32(out, 0); w64(out, offs[i]); w64(out, sizes[i]); }
    uint64_t pos = HEADER_SIZE + SECTION_ENTRY_SIZE * NSEC;

    pad8(out, pos);                                            // DOCS
    w32(out, docNo);
    uint64_t base = 4 + 8ull * docNo;
    for (uint32_t d = 0; d < docNo; d++) w64(out, base + docOff[d]);
    fwrite(docsBlob.a, 1, docsBlob.n, out);
    pos += szDocs; pad8(out, pos);

    w32(out, (uint32_t)T);                                     // DICT (в порядке сортировки)
    for (size_t i = 0; i < T; i++) {
        uint32_t t = order[i];
        w32(out, ix.off[t]); w16(out, ix.len[t]); w16(out, 0);
        w32(out, (uint32_t)(start[t + 1] - start[t]));        // df
        w32(out, 0);                                           // зарезервировано
        w64(out, start[t] * 4);                                // смещение списка в POSTINGS
    }
    pos += szDict; pad8(out, pos);

    fwrite(ix.pool.a, 1, ix.pool.n, out);                      // TERMSTR
    pos += szStr; pad8(out, pos);

    fwrite(postings.a, 4, postings.n, out);                    // POSTINGS
    pos += szPost;
    fclose(out);
    double t1 = now_sec();

    // ---- статистика
    uint64_t termChars = 0;
    for (size_t t = 0; t < T; t++) {
        const unsigned char *p = (const unsigned char *)ix.pool.a + ix.off[t];
        for (int i = 0; i < ix.len[t]; i++) if ((p[i] & 0xC0) != 0x80) termChars++;
    }
    double total = t1 - t0;
    printf("documents          %u\n", docNo);
    printf("text_bytes         %llu\n", (unsigned long long)textBytes);
    printf("tokens             %llu\n", (unsigned long long)tokens);
    printf("avg_token_len      %.3f\n", tokens ? (double)tokenChars / tokens : 0.0);
    if (useStem) printf("wordforms          %zu\n", tt.size);
    printf("terms              %zu\n", T);
    printf("avg_term_len       %.3f\n", T ? (double)termChars / T : 0.0);
    printf("postings           %zu\n", postings.n);
    printf("index_bytes        %llu\n", (unsigned long long)pos);
    printf("time_parse_sec     %.3f\n", tParse - t0);
    printf("time_sort_sec      %.3f\n", tSort - tParse);
    printf("time_write_sec     %.3f\n", t1 - tSort);
    printf("time_total_sec     %.3f\n", total);
    printf("ms_per_doc         %.4f\n", docNo ? total * 1000 / docNo : 0.0);
    printf("ms_per_kb          %.4f\n", textBytes ? total * 1000 / (textBytes / 1024.0) : 0.0);
    return 0;
}

  python lab7.py build        — пересобрать индекс (indexer.exe) и показать статистику

import os, struct
from urllib.parse import unquote
from labtool import DATA, data, fmt, main, run, table

SEC = {1: 'DOCS — прямой индекс', 2: 'DICT — словарь', 3: 'TERMSTR — строки термов', 4: 'POSTINGS — списки документов'}


class Idx:
    def __init__(self, name='index.bin'):
        self.b = open(data(name), 'rb').read()
        b = self.b
        self.magic, self.version, self.nsec, self.flags = b[:4], *struct.unpack_from('<III', b, 4)
        self.secs = {}
        for i in range(self.nsec):
            t, _, off, size = struct.unpack_from('<IIQQ', b, 16 + 24 * i)
            self.secs[t] = (off, size)
        self.docs = self.secs[1][0]; self.dict = self.secs[2][0]
        self.ts = self.secs[3][0]; self.post = self.secs[4][0]
        self.ndocs = struct.unpack_from('<I', b, self.docs)[0]
        self.nterms = struct.unpack_from('<I', b, self.dict)[0]

    def term_at(self, i):
        e = self.dict + 4 + 24 * i
        soff, = struct.unpack_from('<I', self.b, e); ln, = struct.unpack_from('<H', self.b, e + 4)
        df, = struct.unpack_from('<I', self.b, e + 8); poff, = struct.unpack_from('<Q', self.b, e + 16)
        return self.b[self.ts + soff:self.ts + soff + ln].decode('utf-8'), df, poff

    def find(self, w):
        wb = w.encode('utf-8'); lo, hi = 0, self.nterms - 1
        while lo <= hi:
            m = (lo + hi) // 2
            t = self.term_at(m)[0].encode('utf-8')
            if t == wb:
                return m
            lo, hi = (m + 1, hi) if t < wb else (lo, m - 1)
        return -lo - 1

    def postings(self, i, k=None):
        _, df, poff = self.term_at(i)
        k = df if k is None else min(k, df)
        return list(struct.unpack_from(f'<{k}I', self.b, self.post + poff))

    def doc(self, d):
        r = self.docs + struct.unpack_from('<Q', self.b, self.docs + 4 + 8 * d)[0]
        tl, = struct.unpack_from('<H', self.b, r + 5)
        title = self.b[r + 7:r + 7 + tl].decode('utf-8')
        ul, = struct.unpack_from('<H', self.b, r + 7 + tl)
        url = self.b[r + 9 + tl:r + 9 + tl + ul].decode('utf-8')
        return title, unquote(url)
