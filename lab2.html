ЛР2. Поисковый робот#

Задание (lesson-02/homework.md): написать поискового робота. Единственный аргумент — путь к yaml-конфигу с секциями db (база данных) и logic (в том числе задержка между запросами). В базе хранить: нормализованный URL, «сырой» HTML, название источника, дату обкачки (Unix time). Робота можно остановить в любой момент, и он продолжит с того же места. Переобкачивать нужно только изменившиеся документы. Дополнительное требование преподавателя: база данных — распределённая (SQLite не подходит).

1. Что такое поисковый робот#

Робот (crawler, «паук») — программа, которая сама обходит сайты и скачивает страницы для поисковой системы. Базовый цикл:

взять URL из очереди → скачать → разобрать → извлечь ссылки → отфильтровать → новые добавить в очередь → повторить

Архитектура из лекции (как в книге Маннинга) и как она реализована у меня:

Блок Назначение Реализация
URL Frontier очередь адресов на обкачку таблица frontier в CockroachDB, порядок — обход в ширину
Fetch + DNS скачивание страницы requests.Session, пауза logic.delay, повторы при ошибках
Parse разбор HTML, извлечение ссылок BeautifulSoup: подкатегории и статьи со страницы категории
URL filter какие ссылки брать тот же сайт, только статьи и категории, предел глубины и числа категорий
robots filter что разрешено сайтом urllib.robotparser: Disallow, Crawl-delay
Dup URL elim не скачать один адрес дважды нормализация URL + UNIQUE(url) в очереди
Content seen? не хранить одинаковое содержимое канонический URL (<link rel="canonical">) + SHA-1 текста статьи

2. Два типа источников#

  • categories — Википедия. Обход в ширину по дереву категорий от стартовой страницы «Категория:Железнодорожный транспорт»: со страницы категории берутся ссылки на подкатегории (идут в очередь как category) и на статьи (article). Длинные категории разбиты на страницы — ссылка «Следующая страница» тоже добавляется в очередь (is_cont = 1).
  • sitemap — газета «Гудок». Адреса статей берутся из карты сайта (как в ЛР1), 20 000 самых свежих по lastmod.

3. Нормализация URL#

Один документ может иметь много адресов: HTTP://RU.Wikipedia.org/wiki/ВЛ80#История, https://ru.m.wikipedia.org/wiki/%D0%92%D0%9B80, .../wiki/ВЛ80?utm_source=x. Если их не привести к одному виду, робот скачает страницу несколько раз. Правила: нижний регистр схемы и хоста, http → https, мобильная версия → обычная, без якоря #... и мусорных параметров, единое %-кодирование, пробел → _. Ссылки «следующая страница» /w/index.php?title=X&pagefrom=Y приводятся к /wiki/X?pagefrom=Y, потому что путь /w/ запрещён в robots.txt Википедии:

lab2/robot.py — normalize_url строки 42–66
def normalize_url(url, base=None):
    """Приводит URL к единому виду, чтобы одна страница не скачивалась дважды:
    схема и хост в нижнем регистре, http -> https для Википедии, мобильная версия -> обычная, без порта по умолчанию,
    без #фрагмента, единое %-кодирование пути, пробелы -> «_»,
    /w/index.php?title=X&pagefrom=Y -> /wiki/X?pagefrom=Y (путь /w/ запрещён в robots.txt Википедии),
    из параметров остаются только значимые (KEEP_QUERY), отсортированные."""
    if base:
        url = urljoin(base, url)
    p = urlsplit(url.strip())
    scheme = (p.scheme or 'https').lower()
    host = (p.hostname or '').lower()
    if scheme == 'http' and host.endswith('wikipedia.org'):
        scheme = 'https'                      # Википедия доступна только по https
    host = re.sub(r'^([a-z\-]+)\.m\.(wikipedia\.org)$', r'\1.\2', host)
    if p.port and p.port not in (80, 443):
        host = f'{host}:{p.port}'
    path = unquote(p.path).replace(' ', '_')
    query = [(k, v.replace(' ', '_')) for k, v in parse_qsl(p.query, keep_blank_values=False) if k in KEEP_QUERY]
    title = dict(query).get('title')
    query = [(k, v) for k, v in query if k != 'title']
    if path == '/w/index.php' and title:
        path = '/wiki/' + title
    path = quote(path, safe=SAFE)
    q = urlencode(sorted(query), quote_via=quote, safe=SAFE)
    return urlunsplit((scheme, host, path or '/', q, ''))

4. Вежливость: robots.txt, задержка, User-Agent#

Явные правила — robots.txt (проверяется перед каждым адресом, разобранный файл кешируется по хосту); неявные — пауза между запросами, один поток на сайт, честный User-Agent, пауза при 429/5xx:

lab2/robot.py — Robot.allowed строки 146–164
    def allowed(self, url):
        """Разрешает ли robots.txt сайта скачивать этот URL. robots.txt скачивается один раз на хост;
        если в нём указан Crawl-delay для нашего робота, задержка увеличивается до него."""
        if not self.respect_robots:
            return True
        p = urlsplit(url)
        key = f'{p.scheme}://{p.netloc}'
        if key not in self.robots:
            rp = urllib.robotparser.RobotFileParser()
            r = self.get(key + '/robots.txt')
            if r is not None and r.status_code == 200:
                rp.parse(r.text.splitlines())
            else:
                rp.allow_all = True                    # нет robots.txt — ограничений нет
            cd = rp.crawl_delay(self.http.headers['User-Agent'])
            if cd:
                self.delay = max(self.delay, float(cd))
            self.robots[key] = rp
        return self.robots[key].can_fetch(self.http.headers['User-Agent'], url)
lab2/robot.py — Robot.get строки 126–144
    def get(self, url, headers=None):
        """GET с паузой между запросами (logic.delay) и повторами при ошибках."""
        for attempt in range(self.retries):
            wait = self.delay - (time.perf_counter() - self.last_request)
            if wait > 0:
                time.sleep(wait)
            self.last_request = time.perf_counter()
            self.requests_done += 1
            try:
                r = self.http.get(url, headers=headers or {}, timeout=self.timeout)
                if r.status_code in (200, 304, 404):
                    return r
                if r.status_code == 429 or r.status_code >= 500:
                    time.sleep(min(60, 3 * 2 ** attempt))
                    continue
                return r
            except requests.RequestException:
                time.sleep(min(60, 3 * 2 ** attempt))
        return None

5. Очередь и продолжение после остановки#

Вся очередь — в базе данных. Робот берёт самый ранний адрес в состоянии new (ORDER BY id — порядок добавления, то есть обход в ширину), обрабатывает и фиксирует транзакцию после каждой страницы. Поэтому его можно остановить в любой момент (Ctrl+C, выключение компьютера) — при следующем запуске он продолжит с того же адреса, ничего не потеряв и не скачав дважды:

lab2/robot.py — Robot.crawl_frontier строки 284–320
    def crawl_frontier(self):
        """Обход очереди. Возвращает True, если что-то было сделано."""
        did = False
        while not self.stop:
            row = self.db.execute("SELECT id, url, source, kind, depth, is_cont, lastmod FROM frontier "
                                  "WHERE state='new' ORDER BY id LIMIT 1").fetchone()
            if not row:
                self.db.commit()          # закрыть читающую транзакцию: следующий шаг увидит свежие данные
                return did
            did = True
            fid, url, source, kind, depth, _, lastmod = row
            if kind == 'article' and self.db.execute('SELECT 1 FROM documents WHERE url=?', (url,)).fetchone():
                self.db.execute("UPDATE frontier SET state='done' WHERE id=?", (fid,))
                self.db.commit()
                continue
            if not self.allowed(url):
                self.db.execute("UPDATE frontier SET state='skipped', error='robots.txt' WHERE id=?", (fid,))
                self.db.commit()
                continue
            r = self.get(url)
            if r is None or r.status_code != 200:
                err = 'no response' if r is None else f'HTTP {r.status_code}'
                self.db.execute("UPDATE frontier SET state='error', error=? WHERE id=?", (err, fid))
            elif kind == 'category':
                self.process_category(row, r.text)
                self.db.execute("UPDATE frontier SET state='done' WHERE id=?", (fid,))
            else:
                dup = self.duplicate_of(url, source, r)
                if dup:                         # «Content seen?» — этот документ уже есть в базе
                    self.db.execute("UPDATE frontier SET state='duplicate', error=? WHERE id=?", (dup, fid))
                else:
                    self.save_document(self.canonical(url, r), source, r, int(time.time()), lastmod)
                    self.db.execute("UPDATE frontier SET state='done' WHERE id=?", (fid,))
            self.db.commit()   # после каждой страницы: остановка в любой момент ничего не теряет
            self.progress(kind, url)
            if self.max_requests and self.requests_done >= self.max_requests:
                self.stop = True

    def process_category(self, row, html):
        url, source, depth = row[1], row[2], row[4]
        src = self.sources[source]
        soup = BeautifulSoup(html, 'lxml')
        host = urlsplit(url).hostname
        for block_id, kind in (('mw-subcategories', 'category'), ('mw-pages', 'article')):
            block = soup.find(id=block_id)
            if not block:
                continue
            for a in block.find_all('a', href=True):
                link = normalize_url(a['href'], url)
                if urlsplit(link).hostname != host:
                    continue
                text = a.get_text(strip=True).lower()
                if text in ('следующая страница', 'next page'):
                    self.enqueue(link, source, 'category', depth, is_cont=1)   # продолжение списка
                    continue
                if text in ('предыдущая страница', 'previous page') or not urlsplit(link).path.startswith('/wiki/'):
                    continue
                if a.find_parent(class_='redirect-in-category'):
                    continue                    # перенаправление на другую статью — дубликат, не качаем
                if kind == 'category':
                    if depth + 1 <= src['max_depth'] and self.categories_count(source) < src['max_categories']:
                        self.enqueue(link, source, 'category', depth + 1)

6. Дубликаты содержимого#

Разные адреса могут давать одну и ту же статью: перенаправления, статьи-синонимы, копии. Две проверки: канонический URL (<link rel="canonical"> — сайт сам говорит, какой адрес главный) и хеш содержимого — SHA-1 только блока статьи (меню и реклама меняются от запроса к запросу, а статья — нет):

lab2/robot.py — content_hash строки 80–87
def content_hash(html, selector):
    """SHA-1 содержимого статьи. Хешируется не вся страница, а только блок статьи (selector):
    меню, реклама и блоки «популярное» меняются от запроса к запросу, а статья — нет."""
    if selector:
        el = BeautifulSoup(html, 'lxml').select_one(selector)
        if el is not None:
            return hashlib.sha1(el.get_text(' ', strip=True).encode('utf-8')).hexdigest()
    return hashlib.sha1(html).hexdigest()
lab2/robot.py — Robot.duplicate_of строки 249–256
    def duplicate_of(self, url, source, r):
        """URL уже сохранённого документа, который совпадает с этим (по каноническому URL или по содержимому)."""
        canon = self.canonical(url, r)
        if canon != url and self.db.execute('SELECT 1 FROM documents WHERE url=?', (canon,)).fetchone():
            return canon
        row = self.db.execute('SELECT url FROM documents WHERE content_hash=? AND url<>?',
                              (content_hash(r.content, self.selector(source)), canon)).fetchone()
        return row[0] if row else None

7. Переобкачка только изменившихся документов#

  • Википедия отдаёт заголовок Last-Modified. Робот делает условный GET с заголовком If-Modified-Since: <дата>; если страница не менялась, сервер отвечает 304 Not Modified с пустым телом — трафика почти нет.
  • «Гудок» Last-Modified не отдаёт, зато в карте сайта есть lastmod: если дата та же — страница вообще не запрашивается.
  • В обоих случаях новая версия сохраняется, только если изменился хеш статьи (versions + 1, новая crawled_at), иначе обновляется только checked_at.
lab2/robot.py — Robot.recrawl строки 332–376
    def recrawl(self):
        """Переобкачка: проверяем документы, у которых истёк recrawl_interval.
        Источник с sitemap: карта сайта перечитывается, и страница запрашивается, только если её
        lastmod изменился. Остальные: условный GET If-Modified-Since. В обоих случаях новая версия
        сохраняется, только если изменилось содержимое статьи (хеш)."""
        did = False
        pass_start = int(time.time())
        due = pass_start - self.recrawl_interval
        fresh = {}                                    # источник -> {url: lastmod} из перечитанной карты сайта
        for s in self.sources.values():
            if s.get('type') == 'sitemap' and self.db.execute(
                    'SELECT 1 FROM documents WHERE source=? AND checked_at <= ? AND checked_at < ? LIMIT 1',
                    (s['name'], due, pass_start)).fetchone():
                fresh[s['name']] = self.read_sitemap(s)
        while not self.stop:
            now = int(time.time())
            # только документы, проверенные до начала этого прохода, — каждый проверяется один раз
            row = self.db.execute('SELECT url, source, last_modified, content_hash, hash_v, sitemap_lastmod '
                                  'FROM documents WHERE checked_at <= ? AND checked_at < ? ORDER BY checked_at LIMIT 1',
                                  (due, pass_start)).fetchone()
            if not row:
                self.db.commit()
                return did
            did = True
            url, source, last_modified, old_hash, hash_v, sm_old = row
            if source in fresh and fresh[source].get(url) == sm_old and sm_old:
                # дата в карте сайта та же — страница не менялась, запрос не нужен
                self.db.execute('UPDATE documents SET checked_at=? WHERE url=?', (now, url))
                status = 'sitemap: not modified'
            else:
                # условный запрос: сервер вернёт 304 Not Modified и пустое тело, если страница не менялась
                r = self.get(url, {'If-Modified-Since': last_modified} if last_modified else None)
                old = self.stored_hash(url, source, old_hash, hash_v)
                new_lastmod = fresh.get(source, {}).get(url, sm_old)
                if r is not None and r.status_code == 200 and content_hash(r.content, self.selector(source)) != old:
                    self.save_document(url, source, r, now, new_lastmod)   # изменилась — сохраняем новую версию
                    status = 'updated'
                else:
                    self.db.execute('UPDATE documents SET checked_at=?, sitemap_lastmod=? WHERE url=?',
                                    (now, new_lastmod, url))
                    status = 'not modified' if r is not None and r.status_code == 304 else 'same content'
            self.db.commit()
            self.progress('recrawl ' + status, url)
            if self.max_requests and self.requests_done >= self.max_requests:
                self.stop = True

    def save_document(self, url, source, r, now, sitemap_lastmod=None):

        h = content_hash(html, self.selector(source))
        blob = zlib.compress(html, 6) if self.compress else html

8. Распределённая база данных: CockroachDB#

Что такое распределённая БД#

База, которая работает на нескольких узлах (серверах, процессах) как одно целое: приложение подключается к ней как к обычной базе, а внутри данные

  • шардируются — таблица делится на части (в CockroachDB — диапазоны, ranges, по ~512 МБ, упорядоченные по первичному ключу), разные диапазоны могут жить на разных узлах;
  • реплицируются — каждый диапазон хранится в 3 копиях на разных узлах.

SQLite — один файл на одном компьютере, поэтому она не подходит.

Почему CockroachDB#

Реляционная распределённая СУБД (идеи как у Google Spanner): обычный SQL и протокол PostgreSQL (драйвер psycopg), транзакции, работает на Windows одним исполняемым файлом.

Raft — согласование копий#

У каждого диапазона три копии; одна из них — лидер (через неё идут записи). Запись подтверждается, когда её сохранили 2 из 3 копий (большинство, кворум). Если узел с лидером упал, оставшиеся две копии выбирают нового лидера — база продолжает работать. Если упали 2 из 3 — диапазон недоступен (нет кворума), но данные не теряются и вернутся, когда узлы поднимутся.

def connect_any(hosts, database, user, autocommit=False):
    """Подключение к первому доступному узлу кластера."""
    last = None
    for h in hosts:
        host, _, port = h.partition(':')
        try:
            return psycopg.connect(host=host, port=int(port or 26257), user=user, dbname=database,
                                   autocommit=autocommit, connect_timeout=2,
                                   application_name='mai-ir-robot'), h
        except psycopg.OperationalError as e:
            last = e
    raise RuntimeError(f'ни один узел кластера не доступен ({", ".join(hosts)}): {last}')


class Db:
    def __init__(self, cfg):
        cfg = cfg or {}
        self.hosts = cfg.get('hosts') or DEFAULT_HOSTS
        self.database = cfg.get('database', 'robot')
        self.user = cfg.get('user', 'root')
        # база создаётся на кластере при первом запуске
        admin, _ = connect_any(self.hosts, 'defaultdb', self.user, autocommit=True)
        admin.execute(f'CREATE DATABASE IF NOT EXISTS {self.database}')
        admin.close()
        self.conn, self.node = connect_any(self.hosts, self.database, self.user)
        for stmt in SCHEMA:
            self.conn.execute(stmt)
        self.conn.commit()

    @staticmethod
    def _sql(sql):
        return re.sub(r'\?', '%s', sql)

    def execute(self, sql, params=()):
        return self.conn.execute(self._sql(sql), params)

    def commit(self):
        self.conn.commit()

    def rollback(self):
        self.conn.rollback()

    def reconnect(self):
        """Переподключение (к любому живому узлу), если соединение оборвалось."""
        try:
            self.conn.close()
        except Exception:
            pass
        self.conn, self.node = connect_any(self.hosts, self.database, self.user)

    def close(self):
        self.conn.close()

    def drop_database(self):
        """Удалить базу целиком (для тестов)."""
        self.conn.close()
        admin, _ = connect_any(self.hosts, 'defaultdb', self.user, autocommit=True)
        admin.execute(f'DROP DATABASE IF EXISTS {self.database} CASCADE')
        admin.close()

Что я узнал на практике#

Три узла на одном ноутбуке с жёстким диском (HDD) не справлялись: каждая запись идёт на диск в трёх копиях, а антивирус сканировал файлы базы. Узлы не успевали обмениваться подтверждениями («slow heartbeat», «leaderless range»), а при задержке записи на диск больше 20 с CockroachDB сам аварийно останавливал узел (disk stall detected) — защита от повреждения данных. Решение — данные узлов на SSD и исключение для антивируса. Это хорошая иллюстрация того, что распределённая база опирается на быстрые подтверждения записи: медленный диск = медленный консенсус.

11. Вопросы на защите#

  • Почему обход в ширину? Ближние к корню страницы релевантнее, робот не «тонет» в одной ветке.
  • Как не скачать страницу дважды? Нормализация URL + UNIQUE(url) в очереди + PK в документах.
  • Как не хранить одинаковое содержимое? Канонический URL и SHA-1 блока статьи.
  • Как остановить и продолжить? Очередь в БД, транзакция фиксируется после каждой страницы.
  • Как переобкачивать только изменённое? Условный GET (304) / lastmod из sitemap + сравнение хеша.
  • Зачем хешировать только блок статьи? Реклама и меню меняются при каждом запросе.
  • Что такое распределённая БД? Несколько узлов как одна база; диапазоны в 3 копиях; Raft, кворум 2 из 3.
  • Что будет, если упадёт узел? Новый лидер выбирается из оставшихся копий, запись продолжается; робот переподключается к живому узлу (connect_any).
  • Почему CockroachDB, а не MongoDB? Нужна была реляционная распределённая БД; CockroachDB — SQL и протокол PostgreSQL, транзакции, работает на Windows без Docker.

Что делает:

  3. Когда очередь пуста — переобкачка: документы, проверенные давно, проверяются на изменения
     (условный GET If-Modified-Since или дата lastmod из sitemap) и сохраняются заново,
     только если их содержимое изменилось.
Состояние очереди хранится в базе, поэтому робота можно остановить (Ctrl+C) в любой момент:
при следующем запуске он продолжит с того же места.

import yaml

SKIP_PREFIXES = ('Категория:', 'Шаблон:', 'Портал:', 'Википедия:', 'Файл:', 'Модуль:', 'Проект:',
                 'Участник:', 'Обсуждение', 'Служебная:', 'Справка:', 'Category:', 'Template:',
                 'Portal:', 'Wikipedia:', 'File:', 'Module:', 'Help:', 'Draft:', 'User:', 'Talk:', 'Special:')
# Значимые параметры URL (влияют на содержимое страницы): постраничный вывод категорий Википедии
# и номер статьи «Гудка» (?ID=...). Остальные параметры (utm_* и т.п.) отбрасываются.
KEEP_QUERY = ('title', 'pagefrom', 'subcatfrom', 'pageuntil', 'subcatuntil', 'from', 'ID')
SAFE = "/:@!$'()*+,;=-._~"


def normalize_url(url, base=None):
    """Приводит URL к единому виду, чтобы одна страница не скачивалась дважды:
    схема и хост в нижнем регистре, http -> https для Википедии, мобильная версия -> обычная, без порта по умолчанию,
    без #фрагмента, единое %-кодирование пути, пробелы -> «_»,
    /w/index.php?title=X&pagefrom=Y -> /wiki/X?pagefrom=Y (путь /w/ запрещён в robots.txt Википедии),
    из параметров остаются только значимые (KEEP_QUERY), отсортированные."""
    if base:
        url = urljoin(base, url)
    p = urlsplit(url.strip())
    scheme = (p.scheme or 'https').lower()
    host = (p.hostname or '').lower()
    if scheme == 'http' and host.endswith('wikipedia.org'):
        scheme = 'https'                      # Википедия доступна только по https
    host = re.sub(r'^([a-z\-]+)\.m\.(wikipedia\.org)$', r'\1.\2', host)
    if p.port and p.port not in (80, 443):
        host = f'{host}:{p.port}'
    path = unquote(p.path).replace(' ', '_')
    query = [(k, v.replace(' ', '_')) for k, v in parse_qsl(p.query, keep_blank_values=False) if k in KEEP_QUERY]
    title = dict(query).get('title')
    query = [(k, v) for k, v in query if k != 'title']
    if path == '/w/index.php' and title:
        path = '/wiki/' + title
    path = quote(path, safe=SAFE)
    q = urlencode(sorted(query), quote_via=quote, safe=SAFE)
    return urlunsplit((scheme, host, path or '/', q, ''))

def content_hash(html, selector):
    """SHA-1 содержимого статьи. Хешируется не вся страница, а только блок статьи (selector):
    меню, реклама и блоки «популярное» меняются от запроса к запросу, а статья — нет."""
    if selector:
        el = BeautifulSoup(html, 'lxml').select_one(selector)
        if el is not None:
            return hashlib.sha1(el.get_text(' ', strip=True).encode('utf-8')).hexdigest()
    return hashlib.sha1(html).hexdigest()


def parse_sitemap(xml):
    """Разбор sitemap.xml: ([адреса вложенных sitemap], [(url, lastmod)])."""
    children = re.findall(r'<sitemap>\s*<loc>\s*([^<\s]+)\s*</loc>', xml)
    urls = [(u, m or '') for u, m in
            re.findall(r'<url>\s*<loc>\s*([^<\s]+)\s*</loc>(?:\s*<lastmod>\s*([^<\s]+)\s*</lastmod>)?', xml)]
    return children, urls


class Robot:
    def __init__(self, cfg):
        self.cfg = cfg
        logic = cfg['logic']
        self.delay = float(logic.get('delay', 1.0))
        self.timeout = float(logic.get('timeout', 30))
        self.retries = int(logic.get('retries', 5))
        self.compress = bool(logic.get('compress', True))
        self.recrawl_interval = int(logic.get('recrawl_interval', 7 * 24 * 3600))
        self.idle_sleep = int(logic.get('idle_sleep', 600))
        self.exit_when_idle = bool(logic.get('exit_when_idle', False))
        self.max_requests = int(logic.get('max_requests', 0))   # 0 = без ограничения
        self.respect_robots = bool(logic.get('respect_robots', True))
        self.robots = {}                                        # хост -> разобранный robots.txt
        self.sources = {s['name']: s for s in cfg['sources']}
        self.db = Db(cfg['db'])                                 # распределённая БД: кластер CockroachDB
        print(f'БД: CockroachDB, база {self.db.database}, подключение к узлу {self.db.node}', flush=True)
        self.http = requests.Session()
        self.http.headers['User-Agent'] = logic.get('user_agent', 'MAI-IR-robot/1.0')
        self.requests_done = 0
        self.stop = False
        self.last_request = 0.0

    def selector(self, source):
        """CSS-селектор блока статьи для источника (по нему считается хеш содержимого)."""
        return self.sources.get(source, {}).get('content_selector')

    # ---------------------------------------------------------- HTTP
    def get(self, url, headers=None):
        """GET с паузой между запросами (logic.delay) и повторами при ошибках."""
        for attempt in range(self.retries):
            wait = self.delay - (time.perf_counter() - self.last_request)
            if wait > 0:
                time.sleep(wait)
            self.last_request = time.perf_counter()
            self.requests_done += 1
            try:
                r = self.http.get(url, headers=headers or {}, timeout=self.timeout)
                if r.status_code in (200, 304, 404):
                    return r
                if r.status_code == 429 or r.status_code >= 500:
                    time.sleep(min(60, 3 * 2 ** attempt))
                    continue
                return r
            except requests.RequestException:
                time.sleep(min(60, 3 * 2 ** attempt))
        return None

    def allowed(self, url):
        """Разрешает ли robots.txt сайта скачивать этот URL. robots.txt скачивается один раз на хост;
        если в нём указан Crawl-delay для нашего робота, задержка увеличивается до него."""
        if not self.respect_robots:
            return True
        p = urlsplit(url)
        key = f'{p.scheme}://{p.netloc}'
        if key not in self.robots:
            rp = urllib.robotparser.RobotFileParser()
            r = self.get(key + '/robots.txt')
            if r is not None and r.status_code == 200:
                rp.parse(r.text.splitlines())
            else:
                rp.allow_all = True                    # нет robots.txt — ограничений нет
            cd = rp.crawl_delay(self.http.headers['User-Agent'])
            if cd:
                self.delay = max(self.delay, float(cd))
            self.robots[key] = rp
        return self.robots[key].can_fetch(self.http.headers['User-Agent'], url)

    # ---------------------------------------------------------- sitemap
    def read_sitemap(self, src):
        """Все (url, lastmod) из карты сайта источника, подходящие под url_pattern.
        Карта может быть индексом (список вложенных sitemap) — обходим рекурсивно."""
        pattern = re.compile(src['url_pattern'])
        todo, seen, found = [src['sitemap']], set(), {}
        while todo and not self.stop:
            sm = todo.pop(0)
            if sm in seen or not self.allowed(sm):
                continue
            seen.add(sm)
            r = self.get(sm)
            if r is None or r.status_code != 200:
                continue
            children, urls = parse_sitemap(r.text)
            todo += children
            for u, lastmod in urls:
                if pattern.search(u):
                    found[normalize_url(u)] = lastmod
        return found

    # ---------------------------------------------------------- очередь
    def enqueue(self, url, source, kind, depth, is_cont=0, lastmod=None):
        self.db.execute('INSERT INTO frontier(url, source, kind, depth, is_cont, lastmod) '
                        'VALUES (?,?,?,?,?,?) ON CONFLICT (url) DO NOTHING',
                        (url, source, kind, depth, is_cont, lastmod))

    def categories_count(self, source):
        return self.db.execute("SELECT COUNT(*) FROM frontier WHERE source=? AND kind='category' AND is_cont=0",
                               (source,)).fetchone()[0]

    def seed(self):
        for s in self.sources.values():
            if s.get('type', 'categories') == 'sitemap':
                # Карту сайта читаем один раз: если статьи источника уже в очереди — это продолжение работы
                if self.db.execute('SELECT 1 FROM frontier WHERE source=? LIMIT 1', (s['name'],)).fetchone():
                    continue
                found = self.read_sitemap(s)
                # Самые свежие сначала: по lastmod, при равенстве — по URL; берём не больше max_documents
                items = sorted(found.items(), key=lambda t: (t[1], t[0]), reverse=True)
                for url, lastmod in items[:int(s.get('max_documents', len(items)))]:
                    self.enqueue(url, s['name'], 'article', 0, lastmod=lastmod)
                print(f'{s["name"]}: из sitemap взято {min(len(items), int(s.get("max_documents", len(items))))} '
                      f'из {len(items)} подходящих адресов', flush=True)
            else:
                for u in s['seeds']:
                    self.enqueue(normalize_url(u), s['name'], 'category', 0)
        self.db.commit()

    def process_category(self, row, html):
        url, source, depth = row[1], row[2], row[4]
        src = self.sources[source]
        soup = BeautifulSoup(html, 'lxml')
        host = urlsplit(url).hostname
        for block_id, kind in (('mw-subcategories', 'category'), ('mw-pages', 'article')):
            block = soup.find(id=block_id)
            if not block:
                continue
            for a in block.find_all('a', href=True):
                link = normalize_url(a['href'], url)
                if urlsplit(link).hostname != host:
                    continue
                text = a.get_text(strip=True).lower()
                if text in ('следующая страница', 'next page'):
                    self.enqueue(link, source, 'category', depth, is_cont=1)   # продолжение списка
                    continue
                if text in ('предыдущая страница', 'previous page') or not urlsplit(link).path.startswith('/wiki/'):
                    continue
                if a.find_parent(class_='redirect-in-category'):
                    continue                    # перенаправление на другую статью — дубликат, не качаем
                if kind == 'category':
                    if depth + 1 <= src['max_depth'] and self.categories_count(source) < src['max_categories']:
                        self.enqueue(link, source, 'category', depth + 1)
                elif not title_of(link).startswith(SKIP_PREFIXES):
                    self.enqueue(link, source, 'article', depth + 1)

    @staticmethod
    def canonical(url, r):
        """Канонический URL из <link rel="canonical"> (у перенаправлений он указывает на основную статью)."""
        m = re.search(rb'<link rel="canonical" href="([^"]+)"', r.content[:20000])
        return normalize_url(m.group(1).decode('utf-8', 'replace'), url) if m else url

    def duplicate_of(self, url, source, r):
        """URL уже сохранённого документа, который совпадает с этим (по каноническому URL или по содержимому)."""
        canon = self.canonical(url, r)
        if canon != url and self.db.execute('SELECT 1 FROM documents WHERE url=?', (canon,)).fetchone():
            return canon
        row = self.db.execute('SELECT url FROM documents WHERE content_hash=? AND url<>?',
                              (content_hash(r.content, self.selector(source)), canon)).fetchone()
        return row[0] if row else None

    @staticmethod
    def page_title(html, url):
        """Заголовок: <h1 id="firstHeading"> (Википедия), иначе <meta property="og:title">, иначе из URL."""
        soup = BeautifulSoup(html, 'lxml')
        h = soup.find(id='firstHeading')
        if h:
            return h.get_text(strip=True)
        og = soup.find('meta', property='og:title')
        if og and og.get('content'):
            return og['content'].strip()
        return title_of(url)

    def save_document(self, url, source, r, now, sitemap_lastmod=None):
        html = r.content
        h = content_hash(html, self.selector(source))
        blob = zlib.compress(html, 6) if self.compress else html
        self.db.execute(
            'INSERT INTO documents(url, source, title, html, compressed, html_size, content_hash, last_modified,'
            ' crawled_at, checked_at, sitemap_lastmod, hash_v) VALUES (?,?,?,?,?,?,?,?,?,?,?,?)'
            ' ON CONFLICT(url) DO UPDATE SET title=excluded.title, html=excluded.html, compressed=excluded.compressed,'
            ' html_size=excluded.html_size, content_hash=excluded.content_hash, last_modified=excluded.last_modified,'
            ' crawled_at=excluded.crawled_at, checked_at=excluded.checked_at, sitemap_lastmod=excluded.sitemap_lastmod,'
            ' hash_v=excluded.hash_v, versions=documents.versions+1',
            (url, source, self.page_title(html, url), blob, int(self.compress), len(html), h,
             r.headers.get('Last-Modified'), now, now, sitemap_lastmod, HASH_V))

    def crawl_frontier(self):
        """Обход очереди. Возвращает True, если что-то было сделано."""
        did = False
        while not self.stop:
            row = self.db.execute("SELECT id, url, source, kind, depth, is_cont, lastmod FROM frontier "
                                  "WHERE state='new' ORDER BY id LIMIT 1").fetchone()
            if not row:
                self.db.commit()          # закрыть читающую транзакцию: следующий шаг увидит свежие данные
                return did
            did = True
            fid, url, source, kind, depth, _, lastmod = row
            if kind == 'article' and self.db.execute('SELECT 1 FROM documents WHERE url=?', (url,)).fetchone():
                self.db.execute("UPDATE frontier SET state='done' WHERE id=?", (fid,))
                self.db.commit()
                continue
            if not self.allowed(url):
                self.db.execute("UPDATE frontier SET state='skipped', error='robots.txt' WHERE id=?", (fid,))
                self.db.commit()
                continue
            r = self.get(url)
            if r is None or r.status_code != 200:
                err = 'no response' if r is None else f'HTTP {r.status_code}'
                self.db.execute("UPDATE frontier SET state='error', error=? WHERE id=?", (err, fid))
            elif kind == 'category':
                self.process_category(row, r.text)
                self.db.execute("UPDATE frontier SET state='done' WHERE id=?", (fid,))
            else:
                dup = self.duplicate_of(url, source, r)
                if dup:                         # «Content seen?» — этот документ уже есть в базе
                    self.db.execute("UPDATE frontier SET state='duplicate', error=? WHERE id=?", (dup, fid))
                else:
                    self.save_document(self.canonical(url, r), source, r, int(time.time()), lastmod)
                    self.db.execute("UPDATE frontier SET state='done' WHERE id=?", (fid,))
            self.db.commit()   # после каждой страницы: остановка в любой момент ничего не теряет
            self.progress(kind, url)
            if self.max_requests and self.requests_done >= self.max_requests:
                self.stop = True

    def stored_hash(self, url, source, old_hash, hash_v):
        """Хеш сохранённой версии в текущем формате. Документы, скачанные до перехода на хеш
        содержимого статьи (hash_v=1), пересчитываются по сохранённому HTML — без запроса к сайту."""
        if hash_v == HASH_V:
            return old_hash
        blob, compressed = self.db.execute('SELECT html, compressed FROM documents WHERE url=?', (url,)).fetchone()
        h = content_hash(zlib.decompress(blob) if compressed else blob, self.selector(source))
        self.db.execute('UPDATE documents SET content_hash=?, hash_v=? WHERE url=?', (h, HASH_V, url))
        return h

    def recrawl(self):
        """Переобкачка: проверяем документы, у которых истёк recrawl_interval.
        Источник с sitemap: карта сайта перечитывается, и страница запрашивается, только если её
        lastmod изменился. Остальные: условный GET If-Modified-Since. В обоих случаях новая версия
        сохраняется, только если изменилось содержимое статьи (хеш)."""
        did = False
        pass_start = int(time.time())
        due = pass_start - self.recrawl_interval
        fresh = {}                                    # источник -> {url: lastmod} из перечитанной карты сайта
        for s in self.sources.values():
            if s.get('type') == 'sitemap' and self.db.execute(
                    'SELECT 1 FROM documents WHERE source=? AND checked_at <= ? AND checked_at < ? LIMIT 1',
                    (s['name'], due, pass_start)).fetchone():
                fresh[s['name']] = self.read_sitemap(s)
        while not self.stop:
            now = int(time.time())
            # только документы, проверенные до начала этого прохода, — каждый проверяется один раз
            row = self.db.execute('SELECT url, source, last_modified, content_hash, hash_v, sitemap_lastmod '
                                  'FROM documents WHERE checked_at <= ? AND checked_at < ? ORDER BY checked_at LIMIT 1',
                                  (due, pass_start)).fetchone()
            if not row:
                self.db.commit()
                return did
            did = True
            url, source, last_modified, old_hash, hash_v, sm_old = row
            if source in fresh and fresh[source].get(url) == sm_old and sm_old:
                # дата в карте сайта та же — страница не менялась, запрос не нужен
                self.db.execute('UPDATE documents SET checked_at=? WHERE url=?', (now, url))
                status = 'sitemap: not modified'
            else:
                # условный запрос: сервер вернёт 304 Not Modified и пустое тело, если страница не менялась
                r = self.get(url, {'If-Modified-Since': last_modified} if last_modified else None)
                old = self.stored_hash(url, source, old_hash, hash_v)
                new_lastmod = fresh.get(source, {}).get(url, sm_old)
                if r is not None and r.status_code == 200 and content_hash(r.content, self.selector(source)) != old:
                    self.save_document(url, source, r, now, new_lastmod)   # изменилась — сохраняем новую версию
                    status = 'updated'
                else:
                    self.db.execute('UPDATE documents SET checked_at=?, sitemap_lastmod=? WHERE url=?',
                                    (now, new_lastmod, url))
                    status = 'not modified' if r is not None and r.status_code == 304 else 'same content'
            self.db.commit()
            self.progress('recrawl ' + status, url)
            if self.max_requests and self.requests_done >= self.max_requests:
                self.stop = True

    def progress(self, what, url):
        if self.requests_done % 100 == 0 or self.cfg['logic'].get('verbose'):
            docs = self.db.execute('SELECT COUNT(*) FROM documents').fetchone()[0]
            queue = self.db.execute("SELECT COUNT(*) FROM frontier WHERE state='new'").fetchone()[0]
            print(f'[{time.strftime("%H:%M:%S")}] requests={self.requests_done} documents={docs} '
                  f'queue={queue} last={what} {unquote(url)}', flush=True)

    def run(self):
        self.seed()
        while not self.stop:
            busy = self.crawl_frontier()
            busy = self.recrawl() or busy
            if self.stop:
                break
            if not busy:
                if self.exit_when_idle:
                    print('Нечего обкачивать — выход.')
                    break
                time.sleep(self.idle_sleep)   # ждём, пока документы «созреют» для переобкачки
        self.db.commit()
        self.db.close()
        self.http.close()
        print(f'Остановлен. Запросов за запуск: {self.requests_done}')

Запуск:  python migrate_sqlite.py config.yaml data/robot.db
Переносятся обе таблицы целиком: documents (сырой HTML, хеши, даты) и frontier (очередь, её порядок —
номера id сохраняются, поэтому обход продолжается с того же места). Повторный запуск безопасен:
уже перенесённые строки пропускаются (ON CONFLICT DO NOTHING).
"""
import sqlite3, sys, time

import psycopg
import yaml

from db import Db

DOC_COLS = ['url', 'source', 'title', 'html', 'compressed', 'html_size', 'content_hash', 'last_modified',
            'crawled_at', 'checked_at', 'versions', 'sitemap_lastmod', 'hash_v']
FR_COLS = ['id', 'url', 'source', 'kind', 'depth', 'is_cont', 'state', 'error', 'lastmod']


def copy(src, db, table, cols, key, batch):
    total = src.execute(f'SELECT COUNT(*) FROM {table}').fetchone()[0]
    row_ph = '(' + ', '.join(['%s'] * len(cols)) + ')'
    cur = src.execute(f'SELECT {", ".join(cols)} FROM {table} ORDER BY rowid')
    done, t0 = 0, time.time()
    while True:
        rows = cur.fetchmany(batch)
        if not rows:
            break
        for attempt in range(20):           # кластер на одном HDD может ненадолго «задуматься» —
            try:                            # повторяем порцию с паузой (вставка идемпотентна)
                # один многострочный INSERT на порцию: одна запись в журнал Raft вместо записи на каждую строку
                sql = (f'INSERT INTO {table} ({", ".join(cols)}) VALUES {", ".join([row_ph] * len(rows))} '
                       f'ON CONFLICT ({key}) DO NOTHING')
                db.conn.execute(sql, [v for r in rows for v in r])
                db.commit()
                break
            except psycopg.Error as e:
                try:
                    db.rollback()
                except psycopg.Error:
                    db.reconnect()
                print(f'\n  повтор порции ({type(e).__name__}): {str(e)[:80]}', flush=True)
                time.sleep(min(60, 5 * (attempt + 1)))
        else:
            raise RuntimeError('порция не записана после 20 попыток')
        done += len(rows)
        print(f'\r{table}: {done}/{total} ({time.time() - t0:.0f} с)', end='', flush=True)
    print()
    n = db.execute(f'SELECT COUNT(*) FROM {table}').fetchone()[0]
    db.commit()
    print(f'{table}: в SQLite {total}, в CockroachDB {n}')
    return total, n

    src = sqlite3.connect(sys.argv[2])

    print(f'Подключено к узлу {db.node}, база {db.database}')
    ok = True
    for table, cols, key, batch in (('frontier', FR_COLS, 'url', 2000), ('documents', DOC_COLS, 'url', 200)):
        total, n = copy(src, db, table, cols, key, batch)
        ok &= n >= total
    print('ПЕРЕНОС ЗАВЕРШЁН' if ok else 'ВНИМАНИЕ: строк в CockroachDB меньше, чем в SQLite')


if __name__ == '__main__':

def bar(done, total):

// Выполнить SQL на узле host; вывод в формате TSV (первая строка — заголовки). ok = узел ответил.
static std::string sql_on(const std::string &host, const std::string &q, bool *ok = nullptr, const char *db = "robot") {
    // запрос передаётся файлом (--file): в командной строке cmd.exe исказил бы символы % и кавычки
    std::string tmp = std::string(getenv("TEMP") ? getenv("TEMP") : ".") + "\\lab2_query.sql";
    FILE *f = tool::open_file(tmp, "wb");
    std::string body = q;
    while (!body.empty() && isspace((unsigned char)body.back())) body.pop_back();
    if (body.empty() || body.back() != ';') body += ';';                  // клиент требует ; в конце
    if (f) { fwrite(body.data(), 1, body.size(), f); fclose(f); }
    int rc = 0;
    std::string out = tool::run("\"" + tool::quote(crdb()) + " sql --insecure --host=" + host + " --database=" + db +
                                " --format=tsv --file=" + tool::quote(tmp) + "\"", &rc);
    if (ok) *ok = rc == 0;
    return out;
}

// Подключение к первому живому узлу — как connect_any в db.py.
static std::string sql(const std::string &q, std::string *node = nullptr) {
    for (auto &h : HOSTS) {
        bool ok; std::string out = sql_on(h, q, &ok);
        if (ok) { if (node) *node = h; return out; }
        if (out.find("cannot dial") == std::string::npos && out.find("refused") == std::string::npos) {
            if (node) *node = h;                                               // узел ответил, но запрос с ошибкой
            return "ошибка\n" + out;
        }
    }
    return "ни один узел кластера не отвечает — запустите start_cluster.bat\n";
}

// Таблица TSV -> строки и столбцы.
static std::vector<std::vector<std::string>> rows(const std::string &tsv) {
    std::vector<std::vector<std::string>> r;
    size_t p = 0;
    while (p < tsv.size()) {
        size_t q = tsv.find('\n', p); if (q == std::string::npos) q = tsv.size();
        std::string l = tsv.substr(p, q - p); p = q + 1;
        if (!l.empty() && l.back() == '\r') l.pop_back();
        if (l.empty()) continue;
        std::vector<std::string> c; size_t a = 0, b;
        while ((b = l.find('\t', a)) != std::string::npos) { c.push_back(l.substr(a, b - a)); a = b + 1; }
        c.push_back(l.substr(a));
        r.push_back(c);
    }
    return r;
}

// Печать таблицы с выравниванием по ширине столбцов (с учётом кириллицы).
static void print_table(const std::string &tsv) {
    auto r = rows(tsv);
    if (r.empty()) { printf("  (пусто)\n"); return; }
    std::vector<size_t> w;
    for (auto &row : r) for (size_t i = 0; i < row.size(); i++) {
        if (w.size() <= i) w.push_back(0);
        w[i] = std::max(w[i], std::min<size_t>(tool::u8len(row[i]), 60));
    }
    for (size_t k = 0; k < r.size(); k++) {
        printf("  ");
        for (size_t i = 0; i < r[k].size(); i++) printf("%s  ", tool::pad(tool::u8prefix(r[k][i], 60), w[i]).c_str());
        printf("\n");
        if (k == 0) { printf("  "); for (size_t x : w) printf("%s  ", std::string(x, '-').c_str()); printf("\n"); }
    }
}

// ---------------------------------------------------------------- нормализация URL (как normalize_url в robot.py)
static std::string lower_ascii(std::string s) { for (auto &c : s) c = (char)tolower((unsigned char)c); return s; }

static std::string pct_decode(const std::string &s) {
    std::string r;
    for (size_t i = 0; i < s.size(); i++)
        if (s[i] == '%' && i + 2 < s.size() && isxdigit((unsigned char)s[i + 1]) && isxdigit((unsigned char)s[i + 2])) {
            r += (char)strtol(s.substr(i + 1, 2).c_str(), nullptr, 16); i += 2;
        } else r += s[i];
    return r;
}
// %-кодирование: буквы, цифры и символы из safe остаются, остальные байты -> %XX (заглавные).
static std::string pct_encode(const std::string &s, const char *safe) {
    std::string r; char b[4];
    for (unsigned char c : s) {
        if (isalnum(c) || strchr("_.-~", c) || (c && strchr(safe, c))) r += (char)c;
        else { snprintf(b, sizeof b, "%%%02X", c); r += b; }
    }
    return r;
}

static const char *SAFE = "/:@!$'()*+,;=-._~";
static const char *KEEP[] = {"title", "pagefrom", "subcatfrom", "pageuntil", "subcatuntil", "from", "ID"};

static std::string normalize_url(std::string url, const std::string &base = "") {
    while (!url.empty() && isspace((unsigned char)url.back())) url.pop_back();
    while (!url.empty() && isspace((unsigned char)url[0])) url.erase(0, 1);
    if (!base.empty() && url.find("://") == std::string::npos) {            // относительная ссылка
        size_t s = base.find("://"), h = base.find('/', s + 3);
        std::string origin = base.substr(0, h);
        if (url.rfind("//", 0) == 0) url = base.substr(0, s + 1) + url;
        else if (url[0] == '/') url = origin + url;
        else url = base.substr(0, base.rfind('/') + 1) + url;
    }
    size_t hash = url.find('#'); if (hash != std::string::npos) url.resize(hash);           // без #фрагмента
    size_t s = url.find("://");
    std::string scheme = s == std::string::npos ? "https" : lower_ascii(url.substr(0, s));
    std::string rest = s == std::string::npos ? url : url.substr(s + 3);
    size_t slash = rest.find_first_of("/?");
    std::string hostport = lower_ascii(rest.substr(0, slash)), tail = slash == std::string::npos ? "" : rest.substr(slash);
    size_t qm = tail.find('?');
    std::string path = tail.substr(0, qm), query = qm == std::string::npos ? "" : tail.substr(qm + 1);
    std::string host = hostport, port;
    size_t colon = hostport.rfind(':');
    if (colon != std::string::npos) { host = hostport.substr(0, colon); port = hostport.substr(colon + 1); }
    auto ends = [](const std::string &a, const std::string &b) { return a.size() >= b.size() && a.compare(a.size() - b.size(), b.size(), b) == 0; };
    if (scheme == "http" && ends(host, "wikipedia.org")) scheme = "https";                   // Википедия только по https
    size_t m = host.find(".m.wikipedia.org");                                               // мобильная версия -> обычная
    if (m != std::string::npos && m + 16 == host.size()) host = host.substr(0, m) + ".wikipedia.org";
    if (!port.empty() && port != "80" && port != "443") host += ":" + port;
    path = pct_decode(path);
    std::replace(path.begin(), path.end(), ' ', '_');
    std::vector<std::pair<std::string, std::string>> kv;                                     // значимые параметры
    std::string title;
    size_t a = 0;
    while (a <= query.size() && !query.empty()) {
        size_t e = query.find('&', a); if (e == std::string::npos) e = query.size();
        std::string p = query.substr(a, e - a); a = e + 1;
        size_t eq = p.find('=');
        if (eq == std::string::npos || eq + 1 == p.size()) { if (e == query.size()) break; continue; }
        std::string k = pct_decode(p.substr(0, eq)), v = pct_decode(p.substr(eq + 1));
        std::replace(v.begin(), v.end(), '+', ' '); std::replace(v.begin(), v.end(), ' ', '_');
        bool keep = false; for (auto x : KEEP) keep |= k == x;
        if (keep) { if (k == "title") title = v; else kv.push_back({k, v}); }
        if (e == query.size()) break;
    }
    if (path == "/w/index.php" && !title.empty()) path = "/wiki/" + title;
    std::sort(kv.begin(), kv.end());
    std::string q;
    for (auto &x : kv) q += (q.empty() ? "" : "&") + pct_encode(x.first, SAFE) + "=" + pct_encode(x.second, SAFE);
    return scheme + "://" + host + (path.empty() ? "/" : pct_encode(path, SAFE)) + (q.empty() ? "" : "?" + q);
}

// Правила группы «User-agent: *» (или нашего робота); побеждает самое длинное совпавшее правило, Allow при равенстве.
static bool robots_allowed(const std::string &robots, const std::string &path, const std::string &agent = "MAI-IR-robot") {
    struct Rule { bool allow; std::string prefix; };
    std::vector<Rule> mine, star, *cur = nullptr;
    bool lastWasAgent = false;
    size_t p = 0;
    std::vector<std::vector<Rule> *> group;
    while (p <= robots.size()) {
        size_t q = robots.find('\n', p); if (q == std::string::npos) q = robots.size();
        std::string l = robots.substr(p, q - p); p = q + 1;
        size_t h = l.find('#'); if (h != std::string::npos) l.resize(h);
        while (!l.empty() && isspace((unsigned char)l.back())) l.pop_back();
        size_t c = l.find(':');
        if (c != std::string::npos) {
            std::string k = lower_ascii(l.substr(0, c)), v = l.substr(c + 1);
            while (!v.empty() && v[0] == ' ') v.erase(0, 1);
            if (k == "user-agent") {
                if (!lastWasAgent) group.clear();
                if (v == "*") group.push_back(&star);
                else if (lower_ascii(agent).find(lower_ascii(v)) != std::string::npos) group.push_back(&mine);
                lastWasAgent = true;
            } else {
                lastWasAgent = false;
                if ((k == "allow" || k == "disallow") && !v.empty())
                    for (auto *g : group) g->push_back({k == "allow", v});
            }
        }
        if (q == robots.size()) break;
    }
    cur = mine.empty() ? &star : &mine;
    int best = -1; bool allow = true;
    for (auto &r : *cur) {
        std::string pre = r.prefix; bool endAnchor = !pre.empty() && pre.back() == '$';
        if (endAnchor) pre.pop_back();
        size_t star_ = pre.find('*');
        bool match = star_ == std::string::npos ? (endAnchor ? path == pre : path.rfind(pre, 0) == 0)
                                                : path.rfind(pre.substr(0, star_), 0) == 0 && path.find(pre.substr(star_ + 1)) != std::string::npos;
        if (match && ((int)r.prefix.size() > best || ((int)r.prefix.size() == best && r.allow))) { best = (int)r.prefix.size(); allow = r.allow; }
    }
    return allow;
}
