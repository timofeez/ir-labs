ЛР1. Добыча корпуса документов#

Задание (lesson-01/homework.md): выбрать тематику и источники, скачать документы, разобраться, из чего состоит текст (разметка, метаданные), выделить текст, посмотреть существующие поисковики по этим данным и их недостатки, посчитать статистику: размер «сырых» документов, число документов, размер текста, средние значения. Требования курса: ≥ 30 000 документов одной тематики, не менее двух источников в итоговом индексе.

1. Что такое корпус и зачем он нужен#

Корпус — фиксированный набор документов, по которому работает поисковая система. Всё остальное (токенизация, индекс, поиск, статистика) строится над ним. Поэтому корпус должен быть:

  • тематическим — чтобы запросы были осмысленными и было с чем сравнивать выдачу;
  • достаточно большим — 30–50 тыс. документов на «3», больше 1 млн на «5» (тогда индекс не помещается в память, и нужны блочные алгоритмы);
  • из нескольких источников — разные источники дают разную разметку и разный язык, и система должна с этим справляться.

Мой корпус: 65 509 документов по теме «Железнодорожный транспорт»:

Источник Документов «Сырые» данные Чистый текст Слов Слов/док Доля текста
Википедия (ru) 19 290 250 МБ 115 МБ 9,3 млн 480 46 %
Википедия (en) 26 361 333 МБ 120 МБ 20,7 млн 784 36 %
газета «Гудок» 19 858 2 109 МБ 78 МБ 5,9 млн 295 3,7 %
Всего 65 509 2,7 ГБ 313 МБ 36 млн 546 11,6 %

Русская и английская Википедии считаются одним источником (одинаковая разметка wikitext, один способ получения). Второй источник — газета «Гудок» (gudok.ru), отраслевая газета ОАО «РЖД»: другой формат (HTML), другой стиль (новости, интервью), другой способ получения (карта сайта).

2. Архитектура#

Каждый этап сохраняет результат в файл, поэтому этапы независимы: можно перезапустить любой, а после обрыва скачивание продолжается с места остановки.

3. Википедия: обход дерева категорий через API#

Что такое API и почему не скачивать HTML#

MediaWiki API (https://ru.wikipedia.org/w/api.php) — интерфейс для программ: запрос с параметрами, ответ в JSON. Преимущества перед скачиванием HTML-страниц:

  • за один запрос — до 50 статей сразу;
  • текст приходит в wikitext — исходной разметке, без меню, скриптов и оформления;
  • нагрузка на Википедию минимальна, и это официально разрешённый для программ путь.

Категории — это граф, обход в ширину#

В Википедии статьи помещены в категории, категории вложены в другие категории: «Железнодорожный транспорт» → «Локомотивы» → «Электровозы» → «Электровозы России»… Это граф (не дерево: у категории может быть несколько родителей, бывают циклы). Обход в ширину (BFS) идёт по уровням: сначала все категории глубины 1, потом глубины 2 и т. д. Так в корпус сначала попадают самые близкие к теме статьи, а глубина ограничивает «дрейф» в смежные темы.

API отдаёт содержимое категории порциями до 500 элементов. Если элементов больше, в ответе есть поле continue — «закладка», которую нужно передать в следующий запрос:

lab1/src/crawl.py — members строки 27–35
def members(url, cat):
    cont = {}
    while True:
        d = api(url, action='query', list='categorymembers', cmtitle=cat,
                cmlimit=500, cmtype='page|subcat', **cont)
        yield from d['query']['categorymembers']
        if 'continue' not in d:
            return
        cont = d['continue']

Сам обход: seen_cat — множество уже встреченных категорий (защита от циклов), pages — словарь pageid → название (дубликаты статей исключаются автоматически), MAX_CATS = 4000 — предел числа категорий, иначе глубокий обход уходит в автобусы и города:

lab1/src/crawl.py — collect_titles строки 38–52
def collect_titles(name, max_cats):
    url, root, depth = SOURCES[name]
    seen_cat, pages = {root}, {}
    level = [root]
    for dep in range(depth + 1):
        nxt = []
        for cat in level:
            for m in members(url, cat):
                if m['ns'] == 0:
                    pages.setdefault(m['pageid'], m['title'])
                elif m['ns'] == 14 and m['title'] not in seen_cat and len(seen_cat) < max_cats:
                    seen_cat.add(m['title']); nxt.append(m['title'])
        print(f'{name}: depth {dep}, cats {len(seen_cat)}, pages {len(pages)}', flush=True)
        level = nxt
    return pages, len(seen_cat)

Надёжность: повторы с экспоненциальной паузой#

Сеть может ответить ошибкой или сервер — «слишком много запросов» (HTTP 429). Тогда запрос повторяется через 3, 6, 12, 24… секунд (но не больше 60): экспоненциальная задержка (exponential backoff) — стандартный приём, чтобы не «добивать» перегруженный сервер:

lab1/src/crawl.py — api строки 14–24
def api(url, **p):
    p.update(format='json', formatversion=2)
    for attempt in range(8):
        try:
            r = requests.get(url, params=p, headers=UA, timeout=60)
            if r.status_code == 200:
                return r.json()
        except requests.RequestException:
            pass
        time.sleep(min(60, 3 * 2 ** attempt))
    raise RuntimeError('API failed')

Скачивание текстов пачками по 50#

prop=revisions с rvprop=content отдаёт текст последней версии статьи. Каждая статья — одна строка JSON в файле (формат JSON Lines: удобно дописывать и читать построчно). Продолжение после обрыва: перед началом читаем уже скачанные id в множество done и запрашиваем только остальные:

lab1/src/download_all.py — run строки 5–32
def run(name, out):
    ids = [int(l.split('\t')[0]) for l in open(os.path.join(out, f'{name}_titles.tsv'), encoding='utf-8')]
    path = os.path.join(out, f'{name}_raw.jsonl')

    done = set()
    if os.path.exists(path):
        for line in open(path, encoding='utf-8'):
            try:
                done.add(json.loads(line)['id'])
            except ValueError:
                pass
    todo = [i for i in ids if i not in done]
    url = SOURCES[name][0]

    with open(path, 'a', encoding='utf-8') as f:
        for i in range(0, len(todo), 50):
            d = api(url, action='query', prop='revisions|info', rvprop='content|timestamp',
                    rvslots='main', inprop='url', pageids='|'.join(map(str, todo[i:i + 50])))
            for p in d['query']['pages']:
                if 'revisions' not in p:
                    continue
                rev = p['revisions'][0]
                f.write(json.dumps({'source': name, 'id': p['pageid'], 'title': p['title'],
                                    'url': p['fullurl'], 'timestamp': rev['timestamp'],
                                    'wikitext': rev['slots']['main']['content']},
                                   ensure_ascii=False) + '\n')
            f.flush()
            print(f'{name}: {min(len(ids), len(done) + i + 50)}/{len(ids)}', flush=True)

4. «Гудок»: robots.txt и карта сайта#

robots.txt#

Файл в корне сайта (https://gudok.ru/robots.txt), где владелец пишет правила для роботов (стандарт Robots Exclusion Protocol, RFC 9309):

User-Agent: *                         ← для всех роботов
Sitemap: https://gudok.ru/sitemap_index.xml   ← где карта сайта
Disallow: /bitrix/                    ← нельзя: служебные разделы движка
Disallow: /*?print=                   ← нельзя: версии для печати (дубли статей)
Disallow: /*PAGEN_1=                  ← нельзя: листание (дубли)
...
User-Agent: AhrefsBot
Disallow: /                           ← этому роботу запрещён весь сайт

Это просьба, а не защита: технически скачать можно, но честные роботы правила соблюдают. Статьи газеты /newspaper/?ID=… не запрещены. Ссылку на карту сайта я взял из строки Sitemap:.

Карта сайта (sitemap)#

XML-файл, где сайт сам перечисляет свои страницы (стандарт sitemaps.org). Сайты публикуют её, чтобы поисковики нашли все страницы (даже те, на которые мало ссылок) и быстрее узнавали об изменениях. В одном файле — не больше 50 000 адресов, поэтому большие сайты делают индекс карт:

<!-- sitemap_index.xml — список файлов карты -->
<sitemap><loc>https://gudok.ru/sitemap-0001.xml</loc></sitemap>
<!-- sitemap-0001.xml — сами страницы -->
<url><loc>https://gudok.ru/newspaper/?ID=1780369</loc><lastmod>2026-10-15T10:20:00+03:00</lastmod></url>

У «Гудка» 17 файлов, ~752 тыс. адресов (газета, региональные выпуски, новости). Я беру только статьи печатной газеты и 20 000 самых свежих по lastmod:

lab1/src/gudok.py — list_articles строки 30–38
def list_articles(limit):
    index = get(SITEMAP_INDEX).text
    parts = re.findall(r'<loc>([^<]+\.xml)</loc>', index)
    items = []
    for p in parts:
        items += ARTICLE_RE.findall(get(p).text)
        time.sleep(DELAY)
    items.sort(key=lambda t: (t[2], int(t[1])), reverse=True)
    return items[:limit]

Скачивание — по одной странице с паузой DELAY = 0.3 с (вежливость к сайту). Файл сжимается gzip. Если компьютер выключился посреди записи, последняя строка gzip может быть оборвана — при перезапуске файл перечитывается, испорченный хвост отбрасывается:

lab1/src/gudok.py — main строки 41–84
def main(limit, out):
    os.makedirs(out, exist_ok=True)
    urls_path = os.path.join(out, 'gudok_urls.tsv')
    raw_path = os.path.join(out, 'gudok_raw.jsonl.gz')

    if os.path.exists(urls_path):
        items = [tuple(l.rstrip('\n').split('\t')) for l in open(urls_path, encoding='utf-8')]
    else:
        items = list_articles(limit)
        with open(urls_path, 'w', encoding='utf-8') as f:
            for u, i, m in items:
                f.write(f'{u}\t{i}\t{m}\n')
    print(f'gudok: в списке {len(items)} статей', flush=True)

    done = set()
    if os.path.exists(raw_path):
        broken = False
        tmp = raw_path + '.tmp'
        with gzip.open(raw_path, 'rt', encoding='utf-8') as src, gzip.open(tmp, 'wt', encoding='utf-8') as dst:
            try:
                for line in src:
                    d = json.loads(line)
                    dst.write(line)
                    done.add(d['id'])
            except (EOFError, OSError, ValueError):
                broken = True
        os.replace(tmp, raw_path)
        if broken:
            print('gudok: оборванный хвост файла отброшен', flush=True)
    todo = [t for t in items if int(t[1]) not in done]

    with gzip.open(raw_path, 'at', encoding='utf-8') as f:
        for k, (url, aid, lastmod) in enumerate(todo, 1):
            r = get(url)
            time.sleep(DELAY)
            if r is None:
                continue
            html = r.content.decode('utf-8', 'replace')
            og = BeautifulSoup(html, 'lxml').find('meta', property='og:title')
            f.write(json.dumps({'source': 'gudok', 'id': int(aid), 'title': og['content'] if og else '',
                                'url': url, 'timestamp': lastmod, 'html': html}, ensure_ascii=False) + '\n')
            if k % 100 == 0:
                f.flush()
                print(f'gudok: {len(done) + k}/{len(items)}', flush=True)

5. Из чего состоит документ: разметка и метаданные#

Wikitext#

Разметка Пример Что делаем
ссылка [[Транссибирская магистраль\|Транссибу]] оставляем текст ссылки: «Транссибу»
шаблон {{Карточка локомотива \| ...}}, {{нет АИ}} удаляем (это оформление и метаданные)
сноска <ref>Источник</ref> удаляем
форматирование '''жирный''', ''курсив'' убираем кавычки
заголовок == История == оставляем текст заголовка
таблица {\| ... \|} удаляем
файл, категория [[Файл:...]], [[Категория:...]] удаляем

Метаданные Википедии: карточка (infobox: мощность, годы выпуска…) — у 50 % русских статей, координаты — 46 %, категории — 95 %, сноски — 74 %, изображения — 47 %.

HTML «Гудка»#

Страница статьи — это в основном оформление сайта (меню, баннеры, блоки «популярное»); сама статья занимает лишь 3,7 % HTML. Метаданные: номер выпуска газеты, дата, полоса, рубрика, автор, фото.

6. Выделение текста#

Wikitext — цепочка регулярных выражений#

Порядок важен: сначала отрезаются хвостовые разделы (Примечания, Литература), потом комментарии и сноски (внутри них бывают ссылки и шаблоны), потом шаблоны — в цикле, потому что они вложены ({{a|{{b}}}}): регулярка \{\{[^{}]*\}\} за один проход снимает только самый внутренний уровень.

lab1/src/extract.py — clean строки 23–41
def clean(wt):
    t = TAIL.sub('', wt)
    t = COMMENT.sub('', t)
    t = REF.sub('', t)
    for _ in range(5):
        t2 = TEMPLATE.sub('', t)
        if t2 == t:
            break
        t = t2
    t = TABLE.sub('', t)
    t = FILE.sub('', t)
    t = LINK.sub(r'\1', t)
    t = EXTLINK.sub(r'\1', t)
    t = TAG.sub('', t)
    t = HEADING.sub(r'\1', t)
    t = FORMAT.sub('', t)
    t = re.sub(r'^[*#:;]+\s*', '', t, flags=re.M)
    t = re.sub(r'\n{3,}', '\n\n', t)
    return t.strip()

HTML — разбор дерева DOM#

BeautifulSoup с парсером lxml строит дерево страницы; CSS-селектор article.article-block__main-body выбирает блок статьи. Из него удаляются подпись автора и скрипты, <br> превращаются в переводы строк; рубрика в начале («Кадры | …») и короткая жирная подпись в конце распознаются эвристикой:

lab1/src/extract.py — clean_html строки 44–75
def clean_html(html):
    soup = BeautifulSoup(html, 'lxml')
    body = soup.select_one('article.article-block__main-body')
    header = soup.select_one('div.article-header')
    meta = {
        'issue': bool(header and header.find('h2') and 'Выпуск' in header.find('h2').get_text()),
        'photo': bool(header and header.select_one('.article-header__img img')),
        'subheadings': bool(body and body.find('b')),
        'author': bool(body and body.select_one('div.avt')),
        'rubric': False,
    }
    if body is None:
        return '', meta
    for el in body.select('div.avt, script, style'):
        el.decompose()
    for br in body.find_all('br'):
        br.replace_with('\n')
    text = body.get_text()
    m = RUBRIC.match(text)
    if m:
        meta['rubric'] = True
        text = text[m.end():]
    text = re.sub(r'[ \t\xa0]+', ' ', text)
    text = re.sub(r'\n\s*\n\s*(\n\s*)+', '\n\n', text)
    paragraphs = text.strip().split('\n\n')
    bold = body.find_all('b')
    last = paragraphs[-1].strip()
    if bold and bold[-1].get_text(strip=True) and bold[-1].get_text(strip=True) in last \
            and len(last.split()) <= 20 and len(paragraphs) > 1:
        meta['author'] = True
        paragraphs = paragraphs[:-1]
    return '\n\n'.join(p.strip() for p in paragraphs).strip(), meta

10. Вопросы на защите#

  • Почему два источника, если в корпусе три? Русская и английская Википедии — один источник.
  • Почему API, а не HTML? 50 статей за запрос, чистый wikitext, официальный путь для программ.
  • Что такое continue? Закладка: API отдаёт результат порциями и сообщает, откуда продолжить.
  • Почему обход в ширину? Ближние к корню категории релевантнее; глубина ограничивает дрейф темы.
  • Почему шаблоны в цикле? Они вложены; регулярное выражение не умеет считать скобки.
  • Почему регулярки, а не настоящий парсер? Проще и быстрее; недостаток — вложенность любой глубины не понимается (указано в выводах). Альтернатива — action=parse или mwparserfromhell.
  • Что будет при обрыве? Скачанное пропускается (множество done), оборванный хвост gzip отбрасывается.

def members(url, cat):

REF = re.compile(r'<ref[^>/]*/>|<ref[^>]*>.*?</ref>', re.S | re.I)
COMMENT = re.compile(r'<!--.*?-->', re.S)

def clean(wt):
    t = TAIL.sub('', wt)
    t = COMMENT.sub('', t)
    t = REF.sub('', t)
    for _ in range(5):
        t2 = TEMPLATE.sub('', t)
        if t2 == t:
            break
        t = t2
    t = TABLE.sub('', t)
    t = FILE.sub('', t)
    t = LINK.sub(r'\1', t)
    t = EXTLINK.sub(r'\1', t)
    t = TAG.sub('', t)
    t = HEADING.sub(r'\1', t)
    t = FORMAT.sub('', t)
    t = re.sub(r'^[*#:;]+\s*', '', t, flags=re.M)
    t = re.sub(r'\n{3,}', '\n\n', t)
    return t.strip()


def clean_html(html):
    soup = BeautifulSoup(html, 'lxml')
    body = soup.select_one('article.article-block__main-body')
    header = soup.select_one('div.article-header')
    meta = {
        'issue': bool(header and header.find('h2') and 'Выпуск' in header.find('h2').get_text()),
        'photo': bool(header and header.select_one('.article-header__img img')),
        'subheadings': bool(body and body.find('b')),
        'author': bool(body and body.select_one('div.avt')),
        'rubric': False,
    }
    if body is None:
        return '', meta
    for el in body.select('div.avt, script, style'):
        el.decompose()
    for br in body.find_all('br'):
        br.replace_with('\n')
    text = body.get_text()
    m = RUBRIC.match(text)
    if m:
        meta['rubric'] = True
        text = text[m.end():]
    text = re.sub(r'[ \t\xa0]+', ' ', text)
    text = re.sub(r'\n\s*\n\s*(\n\s*)+', '\n\n', text)
    paragraphs = text.strip().split('\n\n')
    bold = body.find_all('b')
    last = paragraphs[-1].strip()
    if bold and bold[-1].get_text(strip=True) and bold[-1].get_text(strip=True) in last \
            and len(last.split()) <= 20 and len(paragraphs) > 1:
        meta['author'] = True
        paragraphs = paragraphs[:-1]
    return '\n\n'.join(p.strip() for p in paragraphs).strip(), meta

            if bins[i] <= w < bins[i + 1]:
                cnt[d['source']][i] += 1; break
    total = [sum(cnt[s][i] for s in SRC) for i in range(len(bins) - 1)]
    m = max(total)
    for i, t in enumerate(total):
        lab = f'{bins[i]}–{bins[i + 1] - 1}' if bins[i + 1] < 10**9 else f'≥{bins[i]}'
        print(f'  {lab:>10} слов  {fmt(t):>7}  ' + '█' * round(40 * t / m))
    print('\n  (ru / en / Гудок по столбцам): ' + '; '.join(
        f'{bins[i]}+: ' + '/'.join(fmt(cnt[s][i]) for s in SRC) for i in range(len(bins) - 1)))
