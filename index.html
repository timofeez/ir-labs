Информационный поиск: лабораторные работы 1–5, 7, 8#

Тема корпуса — «Железнодорожный транспорт». Студент: Григорьев Тимофей Андреевич, группа М8О-408Б-23. Курс: «Информационный поиск», МАИ (репозиторий курса).

Этот сайт — подробная теория по каждой работе на примере моего кода: что требовалось, какие идеи из лекций за этим стоят, как именно это реализовано (с фрагментами и полными файлами исходников), какие получены цифры, что показывать на защите и какие вопросы могут задать.

Как устроена система#

Поисковая система — это конвейер, каждая лабораторная работа — одно его звено:

 Интернет ──► [ЛР2 робот] ──► «сырые» страницы в распределённой БД CockroachDB (3 узла)
     │
     └──► [ЛР1 API Википедии + sitemap «Гудка»] ──► корпус: 65 509 документов, 36 млн слов
                                                        │
               [ЛР3 токенизация]  «Электровозы ВЛ-80» → электровозы | вл | 80
                                                        │
               [ЛР4 стемминг]     электровозы → электровоз
                                                        │
               [ЛР7 индекс]       терм → отсортированный список документов (свой бинарный формат)
                                                        │      ▲
               [ЛР5 закон Ципфа]  частоты термов ───────┘      │
                                                               │
 Пользователь ──► [ЛР8 поиск]  «(электровоз || тепловоз) колея !узкоколейная» → документы

Общие требования курса и как они выполнены#

Требование (README курса) Как выполнено
Корпус ≥ 30 000 документов одной тематики 65 509 документов, «Железнодорожный транспорт»
Не менее двух источников Википедия (русский и английский разделы — один источник) и газета «Гудок»
Основные компоненты — C/C++ без STL, структуры данных — свои токенизатор, стеммер, индексатор, поиск — C++ без STL: свой Vec, хеш-таблица, сортировки
Обвязка, выкачка — любой интерпретируемый язык Python (ЛР1, ЛР2, подготовка корпуса, веб-сервис, графики)
Интерфейс: веб-сервис + утилита командной строки ЛР8: web/server.py (две страницы, 50 результатов, «следующие 50») и search.exe
Тесты на C++ GoogleTest, запуск через CTest: 29 тест-кейсов, в т.ч. проверка на полном корпусе
Распределённая БД (не SQLite) ЛР2: CockroachDB — кластер из 3 узлов, 3 реплики каждого диапазона
Индексация и поиск — на полном корпусе индекс строится по всем 65 509 документам; тест сверяет поиск с эталоном по всем документам
Один отчёт по всем работам Отчёт_ЛР1-8_Григорьев_М8О-408Б-23.pdf (63 стр.)

Утилиты для демонстрации#

Для каждой работы есть утилита: без аргументов — интерактивное меню, с аргументами — одна команда.

Работа Запуск Что умеет
ЛР1 python lab1/lab1.py статистика, метаданные, гистограмма длин, документ «до/после», очистка своего wikitext, robots.txt и sitemap
ЛР2 python lab2/lab2.py состояние кластера, реплики, очередь, документ из БД, отказ узла, нормализация URL, robots.txt, свой SELECT, запуск робота
ЛР3 python lab_boolean/lab3.py токены текста, статистика и скорость, неудачные токены, UTF-8
ЛР4 python lab_boolean/lab4.py основы слов, поиск со стеммингом и без, словоформы основы, P/R/F1, ошибки стемминга
ЛР5 python lab_boolean/lab5.py топ термов, ранг слова, сводка, Ципф/Мандельброт, график
ЛР7 python lab_boolean/lab7.py статистика индекса, разбор файла побайтово, запись словаря, прямой индекс
ЛР8 python lab_boolean/lab8.py поиск, разбор запроса в дерево, замер скорости, веб-сервис
