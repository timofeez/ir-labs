Как запускать#

Все команды выполняются в терминале (VS Code: Terminal → New Terminal) из папки ir_labs, если не сказано другое. Утилиты и тесты написаны на C++ и уже собраны.

0. Перед началом — база данных ЛР2#

База (CockroachDB, 3 узла) нужна только для ЛР2. После перезагрузки компьютера её нужно запустить заново.

Команда Что делает
lab2\start_cluster.bat запускает 3 узла базы (окна crdb-node1..3), ждать ~15 секунд
lab2\bin\lab2.exe cluster проверка: у всех трёх узлов is_live = true — база работает
lab2\stop_cluster.bat корректно остановить базу

Веб-консоль базы: http://localhost:8091.

1. Тесты (C++, GoogleTest + CTest)#

В каждой папке лабы — одна и та же команда:

Команда Что делает Результат
cd lab1 → ctest --preset default тесты ЛР1: очистка вики-разметки, разбор корпуса, весь корпус 100% tests passed out of 14
cd lab2 → ctest --preset default тесты ЛР2: нормализация URL, robots.txt, распределённая БД (нужна запущенная база) 100% tests passed out of 20
cd lab_boolean → ctest --preset default тесты ЛР3–8: токенизатор, стеммер, частоты, индекс, поиск, полный корпус 100% tests passed out of 29
ctest --preset default -R Lab8 только тесты одной лабы (Lab3, Lab4, Lab5, Lab7, Lab8, FullCorpus)
ctest --preset default -N список всех тестов без запуска
bin\test_lab8_search.exe тесты одной лабы напрямую — подробный вывод GoogleTest

cd .. — вернуться в папку ir_labs.

Если пишет, что нет программ — собрать (в папке лабы):

Команда Что делает
cmake --preset default настройка сборки (один раз)
cmake --build --preset default сборка утилит и тестов

2. Утилиты#

Без слов после имени программы открывается меню: ввести номер пункта → Enter, 0 — выход. Можно сразу писать команду: lab8.exe search электровоз.

ЛР1 — корпус: lab1\bin\lab1.exe#

Команда Что показывает
lab1\bin\lab1.exe stats статистика корпуса по источникам: документы, байты, слова, медиана
lab1\bin\lab1.exe meta доля документов с метаданными (карточки, координаты, сноски…)
lab1\bin\lab1.exe lengths гистограмма длины документов
lab1\bin\lab1.exe find электровоз поиск документов по заголовку
lab1\bin\lab1.exe compare 63729 документ до (вики-разметка) и после очистки
lab1\bin\lab1.exe clean очистка своего кусочка вики-разметки (Enter — пример)
lab1\bin\lab1.exe robots robots.txt и карта сайта «Гудка» (живой запрос)
lab1\bin\lab1.exe random случайный документ

ЛР2 — робот и распределённая БД: lab2\bin\lab2.exe#

Команда Что показывает
lab2\bin\lab2.exe cluster 3 узла, шарды (диапазоны) и 3 реплики каждого
lab2\bin\lab2.exe failover отказ узла: первый недоступен → подключение к следующему
lab2\bin\lab2.exe nodes один запрос через каждый узел — данные одинаковые
lab2\bin\lab2.exe stats документы по источникам, размеры, очередь
lab2\bin\lab2.exe frontier очередь обхода по состояниям
lab2\bin\lab2.exe show ВЛ80 документ из базы по заголовку
lab2\bin\lab2.exe normalize нормализация URL (Enter — примеры)
lab2\bin\lab2.exe robots https://ru.wikipedia.org/w/index.php?title=X разрешён ли адрес в robots.txt
lab2\bin\lab2.exe sql "SELECT source, count(*) FROM documents GROUP BY 1" свой SQL-запрос
cd lab2 → python robot.py config.yaml запуск самого робота; Ctrl+C — остановка, повторный запуск продолжает

Синтаксис запросов: пробел или && — И, || — ИЛИ, ! — НЕ, скобки.
