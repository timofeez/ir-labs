Как сдавать: что показывать и что говорить#

Перед сдачей (5 минут)#

  1. Запустить кластер базы ЛР2: двойной щелчок по lab2\start_cluster.bat (или lab2\bin\lab2.exe cluster — проверить, что 3 узла живы).
  2. Проверить тесты C++ (в каждой из папок lab1, lab2, lab_boolean): ctest --preset default → 100% tests passed out of 14 / 20 / 29. Если программ ещё нет: cmake --preset default, затем cmake --build --preset default.
  3. Открыть Отчёт_ЛР1-8_Григорьев_М8О-408Б-23.pdf и этот сайт.

Самые вероятные вопросы (коротко)#

Вопрос Ответ
Сколько источников? Два: Википедия (ru+en — один) и газета «Гудок»
Почему C++ без STL? Требование курса: структуры данных индекса и поиска — свои
Токен vs терм? Вхождение слова vs нормализованная запись словаря
Почему терм длиннее токена? Токены по вхождениям — много коротких частых слов; терм в словаре один раз
Стемминг vs лемматизация? Правила без словаря vs начальная форма по словарю
Закон Ципфа? f·r ≈ const; log-log — прямая с наклоном −1
Обратный индекс? Терм → отсортированный список документов
Почему списки отсортированы? Пересечение двумя указателями за O(m+n)
Сортировки? Пары — подсчётом (O(n), стабильно), словарь — слиянием (O(T log T))
Расширяемый формат? Таблица секций: новые данные — новые секции; флаги в заголовке
Приоритет в запросе? НЕ > И > ИЛИ, парсер — рекурсивный спуск
Как проверяли поиск? Мини-корпус + сверка с перебором всех 65 509 документов на 300 запросах
Распределённая БД? CockroachDB: 3 узла, 3 копии диапазона, Raft, кворум 2 из 3
Остановка робота? Очередь в БД, коммит после каждой страницы
Переобкачка? Условный GET (304) / lastmod из sitemap + SHA-1 статьи

Если что-то не работает#

  • Кластер не отвечает — запустить lab2\start_cluster.bat; подождать 15 с; lab2\bin\lab2.exe cluster.
  • Нет bin\*.exe — cd lab_boolean → cmake --preset default → cmake --build --preset default.
  • Нет data\index.bin — run.bat в lab_boolean (подготовка корпуса и индексов, ~2 мин).
  • Русские буквы «кракозябрами» в cmd — chcp 65001.
